Context Meter

Token usage of the model's context window as a compact ring with a hover breakdown, or a segmented bar with legend and cost.

Category AICrate glowkit-aiFeature aiegui 0.37
Try it liveMore AI

Usage

Add glowkit next to eframe:

cargo add glowkit eframe

Then draw it inside any egui Ui:

use glowkit::prelude::*;
use glowkit::ai::ContextMeter;

ui.add(ContextMeter::new(48_200, 128_000)
    .segment("Input", 30_100)
    .segment("Output", 12_900)
    .segment("Reasoning", 5_200)
    .cost(0.0241));

Prefer to own the code? The glowkit CLI copies this component's source into your project, shadcn-style:

cargo install glowkit-cli
glowkit add ai-context-meter

Equivalent to

If you know this pattern from Vercel AI Elements, assistant-ui and Bencho, Context Meter is the Rust version: an original egui implementation, not a port, that runs natively and in WebAssembly.

About Context Meter

Context Meter is one of 85 components in glowkit's AI category. It lives in the glowkit-ai crate, enabled by the ai feature of glowkit (on by default). It reads its colors from the active glowkit theme, so it matches the rest of your app in light, dark or a custom brand theme, and every color, size and timing has a setter to override it.

Everything an AI app needs on screen: streaming Markdown chat, prompt inputs with attachments, reasoning and chain-of-thought panels, tool calls with live arguments, approvals, diff review, traces, agent trees, run monitors, cost and context meters, voice orbs and MCP server managers. Pair them with glowkit-stream to drive them from a real AG-UI, Vercel AI SDK, ACP, rig or OpenAI-compatible stream.
