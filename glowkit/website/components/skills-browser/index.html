Skills Browser

Agent skills and plugins as cards with search and category tabs; Install fills across the button and morphs into Installed, which offers Remove on hover.

Category AICrate glowkit-agentsFeature agentsegui 0.37
Try it liveMore AI

Usage

Add glowkit next to eframe:

cargo add glowkit eframe

Then draw it inside any egui Ui:

use glowkit::prelude::*;
use glowkit::agents::{Skill, SkillsBrowser};

let mut skills = vec![
    Skill::new("PDF tools", "Lumen Labs", "Documents").desc("Read, fill and merge PDFs").installs(48_200),
    Skill::new("Postgres", "Community", "Data").desc("Query and migrate databases").installed(true),
];
ui.add(SkillsBrowser::new(&mut skills));

Prefer to own the code? The glowkit CLI copies this component's source into your project, shadcn-style:

cargo install glowkit-cli
glowkit add skills-browser

About Skills Browser

Skills Browser is one of 85 components in glowkit's AI category. It lives in the glowkit-agents crate, enabled by the agents feature of glowkit (on by default). It reads its colors from the active glowkit theme, so it matches the rest of your app in light, dark or a custom brand theme, and every color, size and timing has a setter to override it.

Everything an AI app needs on screen: streaming Markdown chat, prompt inputs with attachments, reasoning and chain-of-thought panels, tool calls with live arguments, approvals, diff review, traces, agent trees, run monitors, cost and context meters, voice orbs and MCP server managers. Pair them with glowkit-stream to drive them from a real AG-UI, Vercel AI SDK, ACP, rig or OpenAI-compatible stream.
