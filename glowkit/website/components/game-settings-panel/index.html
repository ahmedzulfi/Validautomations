Game UI

Settings Panel

Tabbed game settings for graphics, audio and controls: segmented sliders, springy toggles, arrow selectors and key rebind rows that capture the next key you press.

Try it liveMore Game UI

Usage

Add glowkit next to eframe:

cargo add glowkit eframe

Then draw it inside any egui Ui:

use glowkit::prelude::*;
use glowkit::interactions::{GameSettings, GameSettingsPanel, GameStyle, GameCue};

let mut settings = GameSettings::default();
ui.add(GameSettingsPanel::new(&mut settings).style(GameStyle::SciFi).cues(&mut cues));

Prefer to own the code? The glowkit CLI copies this component's source into your project, shadcn-style:

cargo install glowkit-cli
glowkit add game-settings-panel

About Settings Panel

Settings Panel is one of 25 components in glowkit's Game UI category. It lives in the glowkit-interactions crate, enabled by the interactions feature of glowkit (on by default). It reads its colors from the active glowkit theme, so it matches the rest of your app in light, dark or a custom brand theme, and every color, size and timing has a setter to override it.

Game interface pieces that take plain game state each frame: main and pause menus, HUD bars with damage trails, minimaps, ammo counters, cooldown icons, hotbars, inventories with tooltips, skill trees, dialogue boxes, quest trackers, loot and achievement popups, kill feeds and scoreboards. Works in Bevy through bevy_egui.
