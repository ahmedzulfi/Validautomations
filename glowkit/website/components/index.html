Components

682 animated components for Rust and egui

Every component here runs natively on Windows, macOS and Linux and in the browser through WebAssembly. Each page has the usage code, the web components it matches and a link to try it live.

Highlights

Agent Sessions

Templates

Supervise coding-agent sessions across your machines: live / needs-input / idle states grouped by device, a streaming transcript with tool calls, a diff panel, an approve / deny bar, usage limits and a new-session composer (Ctrl+N, Enter / Esc).

Trading Terminal

Templates

A live trading terminal: candlesticks with EMA / Bollinger / volume, crosshair, wheel zoom and drag pan; an order book with depth bars and flashing levels, a trade tape, positions with live PnL, order entry (B / S, limit / market) and a watchlist with sparklines.

Game HUD

Game UI

A full shooter / RPG HUD over a live scene: health and mana with damage trails, ability cooldowns, ammo, minimap, kill feed and a dynamic crosshair, all driven by simulated gameplay.

AI Chat

AI

A complete, working chat: type a message and a simulated assistant thinks, calls a tool, cites sources and streams a Markdown answer.

Node Editor

Canvas & Editors

A workflow-automation graph: drag nodes, connect handles with a live bezier preview, box-select, minimap, controls, undo/redo, copy/paste and auto-layout.

Globe 3D

3D

A true-3D lit globe: continents as thousands of dots, glowing arcs with comets between cities, pulsing markers, a graticule and an atmosphere halo. Drag to spin.

Aurora

Backgrounds

Flowing curtains of northern light that drift and shimmer, fading into the background.

Line Chart

Charts

Multi-series lines that draw in, with a snapping crosshair tooltip, clickable legend, glow, gradient and dashed variants.
