Motion Engine

Timeline

A GSAP-style timeline: tweens sequenced with relative positions, labels and overlaps; play, pause, reverse, change speed or scrub.

Category Motion EngineCrate glowkit-motionFeature motionegui 0.37
Try it liveMore Motion Engine

Usage

Add glowkit next to eframe:

cargo add glowkit eframe

Then draw it inside any egui Ui:

use glowkit::prelude::*;
use glowkit::motion::{Timeline, Tween, Playback, Scrubber};

let tl = Timeline::new()
    .add(Tween::new("x", -1.0_f32, 0.0).duration(0.8).ease(Easing::OutBack), ())
    .label("spin")
    .add(Tween::new("rotate", 0.0_f32, 180.0).duration(0.7), "<0.3")  // 0.3s after previous start
    .add(Tween::new("pop", 0.0_f32, 1.0).duration(0.5).ease(Easing::OutBack), "-=0.2") // overlap
    .add(Tween::new("title", 0.0_f32, 1.0), "+=0.1");                  // gap
let pb = Playback::update_with(ui, id, tl.duration(), || Playback::new().looping(true, 0.6));
let x: f32 = tl.value_or("x", pb.time, 0.0);
let mut pb2 = pb;
ui.add(Scrubber::new(&tl, &mut pb2));

Prefer to own the code? The glowkit CLI copies this component's source into your project, shadcn-style:

cargo install glowkit-cli
glowkit add motion-timeline

About Timeline

Timeline is one of 17 components in glowkit's Motion Engine category. It lives in the glowkit-motion crate, enabled by the motion feature of glowkit (on by default). It reads its colors from the active glowkit theme, so it matches the rest of your app in light, dark or a custom brand theme, and every color, size and timing has a setter to override it.

The engine under every glowkit animation, exposed for your own UI: springs, keyframes, GSAP-style timelines, variants with stagger, enter and exit presence, FLIP layout animation, shared elements, drag with inertia and snapping, scroll-linked values, motion paths and shape morphing.
