Spider Button

A glossy red pill with corner cobwebs that shoots sagging web lines at the pointer, splats a web on click and snaps back when you pull away.

Category ButtonsCrate glowkit-interactionsFeature interactionsegui 0.37
Try it liveMore Buttons

Usage

Add glowkit next to eframe:

cargo add glowkit eframe

Then draw it inside any egui Ui:

use glowkit::prelude::*;
use glowkit::interactions::SpiderButton;

ui.add(SpiderButton::new("Spider Button").lines(4));

Prefer to own the code? The glowkit CLI copies this component's source into your project, shadcn-style:

cargo install glowkit-cli
glowkit add spider-button

About Spider Button

Spider Button is one of 30 components in glowkit's Buttons category. It lives in the glowkit-interactions crate, enabled by the interactions feature of glowkit (on by default). It reads its colors from the active glowkit theme, so it matches the rest of your app in light, dark or a custom brand theme, and every color, size and timing has a setter to override it.

Buttons that react: shimmer sweeps, rainbow and moving borders, magnetic pull, ripples, particle bursts, 3D push states, copy buttons with feedback and stateful submit buttons. They return a normal egui Response, so clicked() works as usual.
