Data Display

Data Table

Sortable columns with an animated indicator, row hover, selection with select-all, rich cells and pagination.

Category Data DisplayCrate glowkit-componentsFeature componentsegui 0.37
Try it liveMore Data Display

Usage

Add glowkit next to eframe:

cargo add glowkit eframe

Then draw it inside any egui Ui:

use glowkit::prelude::*;
use glowkit::components::{TableColumn, DataTable};

let cols = vec![
    TableColumn::new("User").flex(2.2),
    TableColumn::new("Role"),
    TableColumn::new("Status"),
    TableColumn::new("Spend").right(),
];
ui.add(DataTable::new(cols, &rows).selection(&mut selected).page_size(5));

Prefer to own the code? The glowkit CLI copies this component's source into your project, shadcn-style:

cargo install glowkit-cli
glowkit add data-table

About Data Table

Data Table is one of 15 components in glowkit's Data Display category. It lives in the glowkit-components crate, enabled by the components feature of glowkit (on by default). It reads its colors from the active glowkit theme, so it matches the rest of your app in light, dark or a custom brand theme, and every color, size and timing has a setter to override it.

Ways to show information: data tables, timelines, stat cards, tree views, syntax-highlighted code blocks and diffs, terminals, globes, avatar groups and empty states.
