Alert Dialog

A blocking confirmation with Cancel / Continue actions and an optional destructive style.

Category Overlays & FeedbackCrate glowkit-componentsFeature componentsegui 0.37
Try it liveMore Overlays & Feedback

Usage

Add glowkit next to eframe:

cargo add glowkit eframe

Then draw it inside any egui Ui:

use glowkit::prelude::*;
use glowkit::components::AlertDialog;

let r = AlertDialog::new(&mut open, "Delete this project?")
    .description("This permanently deletes the project and all of its data.")
    .confirm("Delete project")
    .destructive(true)
    .show(ui);
if r.confirmed { delete(); }

Prefer to own the code? The glowkit CLI copies this component's source into your project, shadcn-style:

cargo install glowkit-cli
glowkit add alert-dialog

About Alert Dialog

Alert Dialog is one of 17 components in glowkit's Overlays & Feedback category. It lives in the glowkit-components crate, enabled by the components feature of glowkit (on by default). It reads its colors from the active glowkit theme, so it matches the rest of your app in light, dark or a custom brand theme, and every color, size and timing has a setter to override it.

Overlays that open and close with springs: toasts, alert dialogs, morphing modals, dynamic-island notifications, guided tours, banners, undo bars, confirm sheets and feedback widgets.
