Motion Engine

Variants & Stagger

Switch one variant name and every child follows, staggered one after another (from the first, or from the center outward).

Category Motion EngineCrate glowkit-motionFeature motionegui 0.37
Try it liveMore Motion Engine

Usage

Add glowkit next to eframe:

cargo add glowkit eframe

Then draw it inside any egui Ui:

use glowkit::prelude::*;
use glowkit::motion::{MotionGroup, Variants};

MotionGroup::new(id, Variants::fade(vec2(-24.0, 0.0)))
    .initial("hidden")
    .animate(if open { "visible" } else { "hidden" })
    .stagger_children(0.06)
    .delay_children(0.1)
    .show(ui, |group, ui| {
        for row in &rows {
            group.child(ui, |ui| { ui.label(row); });
        }
    });

Prefer to own the code? The glowkit CLI copies this component's source into your project, shadcn-style:

cargo install glowkit-cli
glowkit add stagger-variants

If you know this pattern from Framer Motion, Motion One, GSAP and Motion Primitives, Variants & Stagger is the Rust version: an original egui implementation, not a port, that runs natively and in WebAssembly.

About Variants & Stagger

Variants & Stagger is one of 17 components in glowkit's Motion Engine category. It lives in the glowkit-motion crate, enabled by the motion feature of glowkit (on by default). It reads its colors from the active glowkit theme, so it matches the rest of your app in light, dark or a custom brand theme, and every color, size and timing has a setter to override it.

The engine under every glowkit animation, exposed for your own UI: springs, keyframes, GSAP-style timelines, variants with stagger, enter and exit presence, FLIP layout animation, shared elements, drag with inertia and snapping, scroll-linked values, motion paths and shape morphing.
