Solar System

A glowing sun with planets lit from the sun (real day and night sides) on orbit rings, a ringed giant and an orbiting moon. Drag to orbit, hover planets for names.

Category 3DCrate glowkit-3dFeature three-degui 0.37
Try it liveMore 3D

Usage

Add glowkit next to eframe:

cargo add glowkit eframe

Then draw it inside any egui Ui:

use glowkit::prelude::*;
use glowkit::three_d::{SolarSystem, Planet};

ui.add(SolarSystem::new(Planet::samples()).labels(true).height(380.0));

Prefer to own the code? The glowkit CLI copies this component's source into your project, shadcn-style:

cargo install glowkit-cli
glowkit add solar-system

Equivalent to

If you know this pattern from three.js and Spline, Solar System is the Rust version: an original egui implementation, not a port, that runs natively and in WebAssembly.

About Solar System

Solar System is one of 34 components in glowkit's 3D category. It lives in the glowkit-3d crate, enabled by the three-d feature of glowkit (on by default). It reads its colors from the active glowkit theme, so it matches the rest of your app in light, dark or a custom brand theme, and every color, size and timing has a setter to override it.

A software 3D renderer that draws lit, depth-sorted meshes straight into egui: model viewers with orbit controls, globes, particle clouds that morph between shapes, terrains, voxel text, 3D charts and carousels. No wgpu boilerplate, and it runs in WebAssembly too.
