Meter

Quota meters that fill with a spring and shift from blue to amber to red as the limit nears, with a breathing glow when critical.

Category Data DisplayCrate glowkit-interactionsFeature interactionsegui 0.37
Try it liveMore Data Display

Usage

Add glowkit next to eframe:

cargo add glowkit eframe

Then draw it inside any egui Ui:

use glowkit::prelude::*;
use glowkit::interactions::BoardMeter;

ui.add(BoardMeter::new("Storage", 7.2, 10.0).unit("GB"));
ui.add(BoardMeter::new("Seats", 19.0, 20.0).integer().hint("Add seats before inviting more teammates."));
ui.add(BoardMeter::new("API requests this month", 96.0, 100.0).percent());

Prefer to own the code? The glowkit CLI copies this component's source into your project, shadcn-style:

cargo install glowkit-cli
glowkit add board-meter

Equivalent to

If you know this pattern from BoardUI, Meter is the Rust version: an original egui implementation, not a port, that runs natively and in WebAssembly.

About Meter

Meter is one of 15 components in glowkit's Data Display category. It lives in the glowkit-interactions crate, enabled by the interactions feature of glowkit (on by default). It reads its colors from the active glowkit theme, so it matches the rest of your app in light, dark or a custom brand theme, and every color, size and timing has a setter to override it.

Ways to show information: data tables, timelines, stat cards, tree views, syntax-highlighted code blocks and diffs, terminals, globes, avatar groups and empty states.
