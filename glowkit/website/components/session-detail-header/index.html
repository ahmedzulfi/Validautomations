Session Detail Header

The control bar of one agent session: title, repo, branch and device, live state and clock, step pips, token budget, a Needs-you pill, Pause and a hold-to-stop kill switch.

Category AICrate glowkit-agentsFeature agentsegui 0.37
Try it liveMore AI

Usage

Add glowkit next to eframe:

cargo add glowkit eframe

Then draw it inside any egui Ui:

use glowkit::prelude::*;
use glowkit::agents::{SessionDetailHeader, RunState};

let action = SessionDetailHeader::new("Deploy Fixer", "Fix the failing production deploy")
    .meta("acme/web", "fix/missing-zod", "MacBook Pro")
    .state(RunState::Running, 142.0).step(3, 5, "Running the test suite")
    .budget(18_400.0, 50_000.0).needs_you(2).model("Nova 2")
    .show(ui);

Prefer to own the code? The glowkit CLI copies this component's source into your project, shadcn-style:

cargo install glowkit-cli
glowkit add session-detail-header

About Session Detail Header

Session Detail Header is one of 85 components in glowkit's AI category. It lives in the glowkit-agents crate, enabled by the agents feature of glowkit (on by default). It reads its colors from the active glowkit theme, so it matches the rest of your app in light, dark or a custom brand theme, and every color, size and timing has a setter to override it.

Everything an AI app needs on screen: streaming Markdown chat, prompt inputs with attachments, reasoning and chain-of-thought panels, tool calls with live arguments, approvals, diff review, traces, agent trees, run monitors, cost and context meters, voice orbs and MCP server managers. Pair them with glowkit-stream to drive them from a real AG-UI, Vercel AI SDK, ACP, rig or OpenAI-compatible stream.
