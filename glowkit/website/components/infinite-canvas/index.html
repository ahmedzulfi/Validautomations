Infinite Canvas

A pannable, zoomable surface: drag / middle-mouse / space+drag to pan, ctrl+wheel or pinch to zoom smoothly around the cursor, dot / line / cross backgrounds, minimap and fit-to-content.

Category Canvas & EditorsCrate glowkit-canvasFeature canvasegui 0.37
Try it liveMore Canvas & Editors

Usage

Add glowkit next to eframe:

cargo add glowkit eframe

Then draw it inside any egui Ui:

use glowkit::prelude::*;
use glowkit::canvas::{CanvasView, InfiniteCanvas, Background};

let mut view = CanvasView::default(); // keep it in your app state
InfiniteCanvas::new(&mut view)
    .background(Background::Dots)
    .height(480.0)
    .show(ui, |cv| {
        let r = cv.rect_to_screen(Rect::from_min_size(pos2(0.0, 0.0), vec2(200.0, 120.0)));
        cv.painter.rect_filled(r, 12.0 * cv.zoom(), Color32::DARK_GRAY);
    });

Prefer to own the code? The glowkit CLI copies this component's source into your project, shadcn-style:

cargo install glowkit-cli
glowkit add infinite-canvas

About Infinite Canvas

Infinite Canvas is one of 13 components in glowkit's Canvas & Editors category. It lives in the glowkit-canvas crate, enabled by the canvas feature of glowkit (on by default). It reads its colors from the active glowkit theme, so it matches the rest of your app in light, dark or a custom brand theme, and every color, size and timing has a setter to override it.

The heavy pieces of creative and developer tools: a React-Flow-style node editor, shader graphs, flowcharts, an infinite canvas and whiteboard, kanban and gantt boards, mind maps, a timeline editor, a data grid, org charts and a signature pad.
