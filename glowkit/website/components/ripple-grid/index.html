Ripple Grid

Grid lines rippling with waves from the center and the pointer, crests lit in the accent color.

Category BackgroundsCrate glowkit-blocksFeature blocksegui 0.37
Try it liveMore Backgrounds

Usage

Add glowkit next to eframe:

cargo add glowkit eframe

Then draw it inside any egui Ui:

use glowkit::prelude::*;
use glowkit::blocks::RippleGrid;

ui.add(RippleGrid::new().spacing(30.0).amplitude(10.0));

Prefer to own the code? The glowkit CLI copies this component's source into your project, shadcn-style:

cargo install glowkit-cli
glowkit add ripple-grid

About Ripple Grid

Ripple Grid is one of 63 components in glowkit's Backgrounds category. It lives in the glowkit-blocks crate, enabled by the blocks feature of glowkit (on by default). It reads its colors from the active glowkit theme, so it matches the rest of your app in light, dark or a custom brand theme, and every color, size and timing has a setter to override it.

Full-panel animated backgrounds built from vertex-colored meshes, so they stay cheap on the GPU: aurora, silk, plasma, particles, meteors, starfields, beams, grids, waves, liquid metal and dozens more. Paint one behind any egui layout with a single call.
