Skeleton Loader And Reveal

A skeleton row breathes while it waits, then the real avatar and text fade up out of a slight blur as the skeleton melts away.

Category Micro-interactionsCrate glowkit-interactionsFeature interactionsegui 0.37
Try it liveMore Micro-interactions

Usage

Add glowkit next to eframe:

cargo add glowkit eframe

Then draw it inside any egui Ui:

use glowkit::prelude::*;
use glowkit::interactions::SkeletonReveal;

ui.add(SkeletonReveal::new(loaded).name("Jane Cooper").detail("jane.cooper@example.com"));

Prefer to own the code? The glowkit CLI copies this component's source into your project, shadcn-style:

cargo install glowkit-cli
glowkit add tx-skeleton-loader-and-reveal

Equivalent to

If you know this pattern from Transitions.dev, Skeleton Loader And Reveal is the Rust version: an original egui implementation, not a port, that runs natively and in WebAssembly.

About Skeleton Loader And Reveal

Skeleton Loader And Reveal is one of 71 components in glowkit's Micro-interactions category. It lives in the glowkit-interactions crate, enabled by the interactions feature of glowkit (on by default). It reads its colors from the active glowkit theme, so it matches the rest of your app in light, dark or a custom brand theme, and every color, size and timing has a setter to override it.

Small, physical details that make an app feel finished: liquid toggles, slide-to-confirm, swipe actions, reorderable lists, pull to refresh, emoji reactions, rolling counters, success checks, error shakes and notification badges, each tuned with springs.
