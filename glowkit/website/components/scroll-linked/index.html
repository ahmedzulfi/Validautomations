Motion Engine

Scroll-Linked Motion

A progress bar tied to scroll position, parallax layers at different speeds, values mapped with transform(), and cards that animate in when scrolled into view.

Category Motion EngineCrate glowkit-motionFeature motionegui 0.37
Try it liveMore Motion Engine

Usage

Add glowkit next to eframe:

cargo add glowkit eframe

Then draw it inside any egui Ui:

use glowkit::prelude::*;
use glowkit::motion::{InView, scroll_offset, parallax, transform, scroll_progress};

let out = ScrollArea::vertical().show(ui, |ui| {
    let scroll = scroll_offset(ui).y;
    let y = parallax(scroll, 0.5);                       // half speed
    let hue: Color32 = transform(scroll, &[0.0, 400.0], &[a, b]);
    let seen = InView::new(id).amount(0.4).check(ui, card_rect);
});
let progress = scroll_progress(&out).y;

Prefer to own the code? The glowkit CLI copies this component's source into your project, shadcn-style:

cargo install glowkit-cli
glowkit add scroll-linked

About Scroll-Linked Motion

Scroll-Linked Motion is one of 17 components in glowkit's Motion Engine category. It lives in the glowkit-motion crate, enabled by the motion feature of glowkit (on by default). It reads its colors from the active glowkit theme, so it matches the rest of your app in light, dark or a custom brand theme, and every color, size and timing has a setter to override it.

The engine under every glowkit animation, exposed for your own UI: springs, keyframes, GSAP-style timelines, variants with stagger, enter and exit presence, FLIP layout animation, shared elements, drag with inertia and snapping, scroll-linked values, motion paths and shape morphing.
