Checklist

Tick a task and the box pops full, the check draws itself in and the words strike out.

Category Micro-interactionsCrate glowkit-effectsFeature effectsegui 0.37
Try it liveMore Micro-interactions

Usage

Add glowkit next to eframe:

cargo add glowkit eframe

Then draw it inside any egui Ui:

use glowkit::prelude::*;
use glowkit::effects::{TodoItem, TaskChecklist};

let mut tasks = vec![TodoItem::new("Water the ferns"), TodoItem::new("Reply to Ana")];
ui.add(TaskChecklist::new(&mut tasks).bounce(50.0).corner(20.0).box_size(18.0));

Prefer to own the code? The glowkit CLI copies this component's source into your project, shadcn-style:

cargo install glowkit-cli
glowkit add checklist

About Checklist

Checklist is one of 71 components in glowkit's Micro-interactions category. It lives in the glowkit-effects crate, enabled by the effects feature of glowkit (on by default). It reads its colors from the active glowkit theme, so it matches the rest of your app in light, dark or a custom brand theme, and every color, size and timing has a setter to override it.

Small, physical details that make an app feel finished: liquid toggles, slide-to-confirm, swipe actions, reorderable lists, pull to refresh, emoji reactions, rolling counters, success checks, error shakes and notification badges, each tuned with springs.
