Motion Engine

Shape Morph

Outlines morph smoothly between circle, square, star, heart and blob: resampled, aligned and interpolated point by point.

Category Motion EngineCrate glowkit-motionFeature motionegui 0.37
Try it liveMore Motion Engine

Usage

Add glowkit next to eframe:

cargo add glowkit eframe

Then draw it inside any egui Ui:

use glowkit::prelude::*;
use glowkit::motion::{MorphShape, morph_polygon};

ui.add(MorphShape::new().size(220.0));
let mid = morph_polygon(&star, &heart, t);   // any two polygons

Prefer to own the code? The glowkit CLI copies this component's source into your project, shadcn-style:

cargo install glowkit-cli
glowkit add shape-morph

About Shape Morph

Shape Morph is one of 17 components in glowkit's Motion Engine category. It lives in the glowkit-motion crate, enabled by the motion feature of glowkit (on by default). It reads its colors from the active glowkit theme, so it matches the rest of your app in light, dark or a custom brand theme, and every color, size and timing has a setter to override it.

The engine under every glowkit animation, exposed for your own UI: springs, keyframes, GSAP-style timelines, variants with stagger, enter and exit presence, FLIP layout animation, shared elements, drag with inertia and snapping, scroll-linked values, motion paths and shape morphing.
