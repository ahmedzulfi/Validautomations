Data Display

Active Sessions

Signed-in devices: sign one out and its row spins then folds away; sign out the rest and they fold one after another; restore unfolds them.

Category Data DisplayCrate glowkit-interactionsFeature interactionsegui 0.37
Try it liveMore Data Display

Usage

Add glowkit next to eframe:

cargo add glowkit eframe

Then draw it inside any egui Ui:

use glowkit::prelude::*;
use glowkit::interactions::ActiveSessions;

ui.add(ActiveSessions::new().delay(0.8));

Prefer to own the code? The glowkit CLI copies this component's source into your project, shadcn-style:

cargo install glowkit-cli
glowkit add active-sessions

Equivalent to

If you know this pattern from ObsidianUI, Active Sessions is the Rust version: an original egui implementation, not a port, that runs natively and in WebAssembly.

About Active Sessions

Active Sessions is one of 15 components in glowkit's Data Display category. It lives in the glowkit-interactions crate, enabled by the interactions feature of glowkit (on by default). It reads its colors from the active glowkit theme, so it matches the rest of your app in light, dark or a custom brand theme, and every color, size and timing has a setter to override it.

Ways to show information: data tables, timelines, stat cards, tree views, syntax-highlighted code blocks and diffs, terminals, globes, avatar groups and empty states.
