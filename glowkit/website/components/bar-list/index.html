Bar List & Progress List

Ranked horizontal bars with labels inside and values on the right, plus labelled progress bars against targets.

Category ChartsCrate glowkit-chartsFeature chartsegui 0.37
Try it liveMore Charts

Usage

Add glowkit next to eframe:

cargo add glowkit eframe

Then draw it inside any egui Ui:

use glowkit::prelude::*;
use glowkit::charts::{BarList, ProgressList};

ui.add(BarList::new(&pages).sorted(true).share(true));
ui.add(ProgressList::new(&spend, &budgets).format(dollars));

Prefer to own the code? The glowkit CLI copies this component's source into your project, shadcn-style:

cargo install glowkit-cli
glowkit add bar-list

Equivalent to

If you know this pattern from Tremor and shadcn/ui, Bar List & Progress List is the Rust version: an original egui implementation, not a port, that runs natively and in WebAssembly.

About Bar List & Progress List

Bar List & Progress List is one of 29 components in glowkit's Charts category. It lives in the glowkit-charts crate, enabled by the charts feature of glowkit (on by default). It reads its colors from the active glowkit theme, so it matches the rest of your app in light, dark or a custom brand theme, and every color, size and timing has a setter to override it.

Charts that draw in and respond to the pointer: line, area, bar, pie and donut, radar, radial, gauges, sparklines, scatter, heatmaps and calendar heatmaps, funnels, treemaps, candlesticks, Sankey diagrams and KPI tiles.
