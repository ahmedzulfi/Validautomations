Agent Tree

An orchestrator and its sub-agents as a live tree of cards: status, model, task, cost and time on each, lights running along connectors to working agents, branches that fold.

Usage

Add glowkit next to eframe:

cargo add glowkit eframe

Then draw it inside any egui Ui:

use glowkit::prelude::*;
use glowkit::agents::{AgentNode, RunState, AgentTree};

let root = AgentNode::new("Orchestrator", "Nova Ultra").state(RunState::Running)
    .task("Launch the new pricing page")
    .child(AgentNode::new("Researcher", "Nova 2").state(RunState::Running).cost(0.06)
        .child(AgentNode::new("Scraper", "Nova Flash").state(RunState::Done)))
    .child(AgentNode::new("Writer", "Nova 2").state(RunState::NeedsInput));
ui.add(AgentTree::new(&root).title("Agents"));

Prefer to own the code? The glowkit CLI copies this component's source into your project, shadcn-style:

cargo install glowkit-cli
glowkit add agent-tree

About Agent Tree

Agent Tree is one of 84 components in glowkit's AI category. It lives in the glowkit-agents crate, enabled by the agents feature of glowkit (on by default). It reads its colors from the active glowkit theme, so it matches the rest of your app in light, dark or a custom brand theme, and every color, size and timing has a setter to override it.

Everything an AI app needs on screen: streaming Markdown chat, prompt inputs with attachments, reasoning and chain-of-thought panels, tool calls with live arguments, approvals, diff review, traces, agent trees, run monitors, cost and context meters, voice orbs and MCP server managers. Pair them with glowkit-stream to drive them from a real AG-UI, Vercel AI SDK, ACP, rig or OpenAI-compatible stream.

More in AI

Run Timeline

AI

An agent run as a quiet trail of steps: tool calls with live spinners, finished steps that fold, a failed step with its error and Retry, and a light running down the rail.

Run Monitor

AI

Live agent runs in one table: filter tabs with rolling counts, status, step progress, ticking elapsed time, tokens and a cost sparkline; rows glide as runs change state.

Handoff Card

AI

A relay hand-off between two agents: a baton travels the track, the receiver lights up, and the context that went along drops in while what got lost is struck through.

Plan Board

AI

An agent's plan as a four-column board: step cards with agent, tool and live progress lift and glide from Planned to Running to Review to Done.

Trace Waterfall

AI

A run's trace as a waterfall: summary strip, folding span tree, bars by kind on a time axis with duration and cost, the slowest call tagged, a live now-line and hover details.

Voice Mode Overlay

AI

A voice conversation overlay that grows out of the mic button: living orb, shimmering status, live captions and call controls.
