CTA Banner

Closing call-to-action: gradient panel, beam-bordered dark panel, split card or minimal centered copy.

Category BlocksCrate glowkit-templatesFeature templatesegui 0.37
Try it liveMore Blocks

Usage

Add glowkit next to eframe:

cargo add glowkit eframe

Then draw it inside any egui Ui:

use glowkit::prelude::*;
use glowkit::templates::{CtaSection, CtaLayout};

CtaSection::new("Ready to build something beautiful?")
    .primary_cta("Get started free")
    .layout(CtaLayout::Beam)
    .show(ui);

Prefer to own the code? The glowkit CLI copies this component's source into your project, shadcn-style:

cargo install glowkit-cli
glowkit add cta-section

Equivalent to

If you know this pattern from MVP Blocks, Tailark and shadcnblocks, CTA Banner is the Rust version: an original egui implementation, not a port, that runs natively and in WebAssembly.

About CTA Banner

CTA Banner is one of 28 components in glowkit's Blocks category. It lives in the glowkit-templates crate, enabled by the templates feature of glowkit (on by default). It reads its colors from the active glowkit theme, so it matches the rest of your app in light, dark or a custom brand theme, and every color, size and timing has a setter to override it.

Ready-made sections you compose into screens: heroes, feature grids and bento layouts, pricing, testimonials, FAQs, teams, changelogs, logo clouds and device mockups.
