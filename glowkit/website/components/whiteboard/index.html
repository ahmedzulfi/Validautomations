Whiteboard

An infinite whiteboard: pen with pressure-like strokes, highlighter, shapes, arrows that stick to shapes, text, sticky notes, eraser, resize / rotate handles, a hand-drawn sketchy style, layers, undo and JSON export.

Category Canvas & EditorsCrate glowkit-canvasFeature canvasegui 0.37
Try it liveMore Canvas & Editors

Usage

Add glowkit next to eframe:

cargo add glowkit eframe

Then draw it inside any egui Ui:

use glowkit::prelude::*;
use glowkit::canvas::{Document, WbShape, ShapeKind, Whiteboard, WhiteboardState};

let mut doc = Document::default();
doc.add(WbShape::sticky(pos2(0.0, 0.0), "Ship it!", STICKY_COLORS[0]));
doc.add(WbShape::new(ShapeKind::Rect, Rect::from_min_size(pos2(220.0, 0.0), vec2(160.0, 90.0))).sketchy(true).label("API"));

Whiteboard::new(&mut doc, &mut state).height(480.0).show(ui);
let json = doc.to_json();                  // export
let doc2 = Document::from_json(&json)?;    // import

Prefer to own the code? The glowkit CLI copies this component's source into your project, shadcn-style:

cargo install glowkit-cli
glowkit add whiteboard

About Whiteboard

Whiteboard is one of 13 components in glowkit's Canvas & Editors category. It lives in the glowkit-canvas crate, enabled by the canvas feature of glowkit (on by default). It reads its colors from the active glowkit theme, so it matches the rest of your app in light, dark or a custom brand theme, and every color, size and timing has a setter to override it.

The heavy pieces of creative and developer tools: a React-Flow-style node editor, shader graphs, flowcharts, an infinite canvas and whiteboard, kanban and gantt boards, mind maps, a timeline editor, a data grid, org charts and a signature pad.

Shader Graph
