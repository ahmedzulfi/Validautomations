Data Table Result

A tool result as a sortable data table: rows slide in, numbers align, deltas are colored pills.

Category AICrate glowkit-agentsFeature agentsegui 0.37
Try it liveMore AI

Usage

Add glowkit next to eframe:

cargo add glowkit eframe

Then draw it inside any egui Ui:

use glowkit::prelude::*;
use glowkit::agents::{ColumnKind, DataTableResult};

let cols = [("Region", ColumnKind::Text), ("Revenue", ColumnKind::Number), ("QoQ", ColumnKind::Delta)];
ui.add(DataTableResult::new("warehouse.query", &cols, &rows).subtitle("SELECT ...").max_rows(6));

Prefer to own the code? The glowkit CLI copies this component's source into your project, shadcn-style:

cargo install glowkit-cli
glowkit add asst-tool-table

Equivalent to

If you know this pattern from Tool UI, assistant-ui and CopilotKit, Data Table Result is the Rust version: an original egui implementation, not a port, that runs natively and in WebAssembly.

About Data Table Result

Data Table Result is one of 85 components in glowkit's AI category. It lives in the glowkit-agents crate, enabled by the agents feature of glowkit (on by default). It reads its colors from the active glowkit theme, so it matches the rest of your app in light, dark or a custom brand theme, and every color, size and timing has a setter to override it.

Everything an AI app needs on screen: streaming Markdown chat, prompt inputs with attachments, reasoning and chain-of-thought panels, tool calls with live arguments, approvals, diff review, traces, agent trees, run monitors, cost and context meters, voice orbs and MCP server managers. Pair them with glowkit-stream to drive them from a real AG-UI, Vercel AI SDK, ACP, rig or OpenAI-compatible stream.
