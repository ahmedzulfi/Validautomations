File Diff

An agent's file change: the header springs open into the diff, removed lines strike through and added lines type themselves in, then the check lights up.

Category AICrate glowkit-interactionsFeature interactionsegui 0.37
Try it liveMore AI

Usage

Add glowkit next to eframe:

cargo add glowkit eframe

Then draw it inside any egui Ui:

use glowkit::prelude::*;
use glowkit::interactions::FileDiff;

ui.add(
    FileDiff::new("src/runner.rs")
        .context("pub fn run(job: &Job) -> Result<()> {")
        .removed("    job.start()?;")
        .added("    job.start_with_retry(3)?;")
        .added("    log::info!(\"started {}\", job.id);")
        .context("    Ok(())")
        .context("}"),
);

Prefer to own the code? The glowkit CLI copies this component's source into your project, shadcn-style:

cargo install glowkit-cli
glowkit add beui-file-diff

If you know this pattern from beUI, File Diff is the Rust version: an original egui implementation, not a port, that runs natively and in WebAssembly.

About File Diff

File Diff is one of 84 components in glowkit's AI category. It lives in the glowkit-interactions crate, enabled by the interactions feature of glowkit (on by default). It reads its colors from the active glowkit theme, so it matches the rest of your app in light, dark or a custom brand theme, and every color, size and timing has a setter to override it.

Everything an AI app needs on screen: streaming Markdown chat, prompt inputs with attachments, reasoning and chain-of-thought panels, tool calls with live arguments, approvals, diff review, traces, agent trees, run monitors, cost and context meters, voice orbs and MCP server managers. Pair them with glowkit-stream to drive them from a real AG-UI, Vercel AI SDK, ACP, rig or OpenAI-compatible stream.
