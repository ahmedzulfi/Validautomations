Command Palette

A ⌘K / Ctrl+K palette: modal search with grouped fuzzy results, a gliding highlight and full keyboard navigation.

Category NavigationCrate glowkit-componentsFeature componentsegui 0.37
Try it liveMore Navigation

Usage

Add glowkit next to eframe:

cargo add glowkit eframe

Then draw it inside any egui Ui:

use glowkit::prelude::*;
use glowkit::components::{CommandPalette, CommandItem, LineIcon};

CommandPalette::toggle_on_shortcut(ui.ctx(), &mut open);
if let Some(cmd) = CommandPalette::new(&mut open)
    .group("Suggestions", vec![
        CommandItem::new("Calendar").icon(LineIcon::Calendar),
        CommandItem::new("Search Emoji").icon(LineIcon::Star),
    ])
    .group("Settings", vec![
        CommandItem::new("Profile").icon(LineIcon::User).shortcut("Ctrl+P"),
    ])
    .show(ui)
{
    run(cmd);
}

Prefer to own the code? The glowkit CLI copies this component's source into your project, shadcn-style:

cargo install glowkit-cli
glowkit add command-palette

Equivalent to

If you know this pattern from shadcn/ui, cmdk, Origin UI, Kibo UI and suiss/ui, Command Palette is the Rust version: an original egui implementation, not a port, that runs natively and in WebAssembly.

About Command Palette

Command Palette is one of 18 components in glowkit's Navigation category. It lives in the glowkit-components crate, enabled by the components feature of glowkit (on by default). It reads its colors from the active glowkit theme, so it matches the rest of your app in light, dark or a custom brand theme, and every color, size and timing has a setter to override it.

Menus and navigation that move with intent: bubble, pill, gooey and staggered menus, card navs, floating and resizable navbars, sidebars, command palettes, tables of contents and morphing tab bars.
