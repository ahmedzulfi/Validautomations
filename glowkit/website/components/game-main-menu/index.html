Main Menu

A title screen over a parallax scene: the title drops in letter by letter and breathes with a glow, entries stagger in and slide on hover, and every hover / confirm is reported as a sound cue.

Usage

Add glowkit next to eframe:

cargo add glowkit eframe

Then draw it inside any egui Ui:

use glowkit::prelude::*;
use glowkit::interactions::{GameMainMenu, GameStyle, GameCue};

let mut cues = Vec::new();
ui.add(GameMainMenu::new(&mut sel, &["Continue", "New Game", "Settings", "Credits", "Quit"])
    .title("Astral Drift")
    .subtitle("Chapter III · The Sunken Vault")
    .style(GameStyle::SciFi)
    .activated(&mut chosen)
    .cues(&mut cues));
for cue in cues { audio.play(cue); }

Prefer to own the code? The glowkit CLI copies this component's source into your project, shadcn-style:

cargo install glowkit-cli
glowkit add game-main-menu

About Main Menu

Main Menu is one of 25 components in glowkit's Game UI category. It lives in the glowkit-interactions crate, enabled by the interactions feature of glowkit (on by default). It reads its colors from the active glowkit theme, so it matches the rest of your app in light, dark or a custom brand theme, and every color, size and timing has a setter to override it.

Game interface pieces that take plain game state each frame: main and pause menus, HUD bars with damage trails, minimaps, ammo counters, cooldown icons, hotbars, inventories with tooltips, skill trees, dialogue boxes, quest trackers, loot and achievement popups, kill feeds and scoreboards. Works in Bevy through bevy_egui.
