Text Animations

Line Shadow Text

Bold text with an offset shadow made of diagonal stripes that keep sliding through it.

Category Text AnimationsCrate glowkit-textFeature textegui 0.37
Try it liveMore Text Animations

Usage

Add glowkit next to eframe:

cargo add glowkit eframe

Then draw it inside any egui Ui:

use glowkit::prelude::*;
use glowkit::text::LineShadowText;

ui.add(LineShadowText::new("Shadow").size(110.0));
ui.add(LineShadowText::new("colored").shadow_color(theme.accent));

Prefer to own the code? The glowkit CLI copies this component's source into your project, shadcn-style:

cargo install glowkit-cli
glowkit add line-shadow-text

Equivalent to

If you know this pattern from Magic UI, Line Shadow Text is the Rust version: an original egui implementation, not a port, that runs natively and in WebAssembly.

About Line Shadow Text

Line Shadow Text is one of 57 components in glowkit's Text Animations category. It lives in the glowkit-text crate, enabled by the text feature of glowkit (on by default). It reads its colors from the active glowkit theme, so it matches the rest of your app in light, dark or a custom brand theme, and every color, size and timing has a setter to override it.

Per-glyph text effects drawn straight into egui: shimmering and gradient text, blur and split reveals, decrypting and scrambling characters, typewriters, rotating words, counters that roll to a value, glitch, wave and proximity effects. Each one is a single widget you add with ui.add().
