Agent Thinking

Four thinking indicators (dot wave, dot spin, stars, infinity comet), each with a shimmering label and an elapsed timer.

Category AICrate glowkit-interactionsFeature interactionsegui 0.37
Try it liveMore AI

Usage

Add glowkit next to eframe:

cargo add glowkit eframe

Then draw it inside any egui Ui:

use glowkit::prelude::*;
use glowkit::interactions::{BoardAgentThinking, BoardThinkingStyle};

ui.add(BoardAgentThinking::new("Thinking").style(BoardThinkingStyle::Infinity));

Prefer to own the code? The glowkit CLI copies this component's source into your project, shadcn-style:

cargo install glowkit-cli
glowkit add board-agent-thinking

Equivalent to

If you know this pattern from BoardUI, Agent Thinking is the Rust version: an original egui implementation, not a port, that runs natively and in WebAssembly.

About Agent Thinking

Agent Thinking is one of 85 components in glowkit's AI category. It lives in the glowkit-interactions crate, enabled by the interactions feature of glowkit (on by default). It reads its colors from the active glowkit theme, so it matches the rest of your app in light, dark or a custom brand theme, and every color, size and timing has a setter to override it.

Everything an AI app needs on screen: streaming Markdown chat, prompt inputs with attachments, reasoning and chain-of-thought panels, tool calls with live arguments, approvals, diff review, traces, agent trees, run monitors, cost and context meters, voice orbs and MCP server managers. Pair them with glowkit-stream to drive them from a real AG-UI, Vercel AI SDK, ACP, rig or OpenAI-compatible stream.
