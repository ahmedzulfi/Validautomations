Agent Fleet Grid

Many agents as tiles with status rings: progress arcs with a glowing head while working, a pulsing amber ring when one needs you, red on failure, plus runs and success rate.

Category AICrate glowkit-agentsFeature agentsegui 0.37
Try it liveMore AI

Usage

Add glowkit next to eframe:

cargo add glowkit eframe

Then draw it inside any egui Ui:

use glowkit::prelude::*;
use glowkit::agents::{FleetAgent, RunState, AgentFleetGrid};

let fleet = vec![
    FleetAgent::new("Deploy Fixer", "DevOps", RunState::Running).activity(0.4, "Reading build logs").stats(31, 0.97),
    FleetAgent::new("Data Loader", "Data", RunState::NeedsInput).activity(0.7, "Which region first?"),
];
ui.add(AgentFleetGrid::new(&fleet));

Prefer to own the code? The glowkit CLI copies this component's source into your project, shadcn-style:

cargo install glowkit-cli
glowkit add agent-fleet-grid

About Agent Fleet Grid

Agent Fleet Grid is one of 84 components in glowkit's AI category. It lives in the glowkit-agents crate, enabled by the agents feature of glowkit (on by default). It reads its colors from the active glowkit theme, so it matches the rest of your app in light, dark or a custom brand theme, and every color, size and timing has a setter to override it.

Everything an AI app needs on screen: streaming Markdown chat, prompt inputs with attachments, reasoning and chain-of-thought panels, tool calls with live arguments, approvals, diff review, traces, agent trees, run monitors, cost and context meters, voice orbs and MCP server managers. Pair them with glowkit-stream to drive them from a real AG-UI, Vercel AI SDK, ACP, rig or OpenAI-compatible stream.

More in AI

Run Monitor

AI

Live agent runs in one table: filter tabs with rolling counts, status, step progress, ticking elapsed time, tokens and a cost sparkline; rows glide as runs change state.

Plan Board

AI

An agent's plan as a four-column board: step cards with agent, tool and live progress lift and glide from Planned to Running to Review to Done.

Agent Tree

AI

An orchestrator and its sub-agents as a live tree of cards: status, model, task, cost and time on each, lights running along connectors to working agents, branches that fold.

Cost Meter

AI

Spend against a budget: a big gliding total, a budget bar that turns amber and then red with a pulsing over-limit tag, tokens in and out, and spend split by model.

Schedule List

AI

Scheduled agent jobs with countdown rings, ticking next-run times, pips for recent outcomes, Run now and on/off switches; jobs fire and record their result.

MCP Server List

AI

MCP servers with connect status, transport, tool counts, latency bars and switches; switching one on plays a handshake, rows unfold to their tools.
