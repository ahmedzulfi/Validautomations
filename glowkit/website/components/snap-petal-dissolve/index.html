Petal Dissolve

A word erodes into tumbling red and white petals, then time runs backwards and every petal flies home to rebuild it.

Category Text AnimationsCrate glowkit-interactionsFeature interactionsegui 0.37
Try it liveMore Text Animations

Usage

Add glowkit next to eframe:

cargo add glowkit eframe

Then draw it inside any egui Ui:

use glowkit::prelude::*;
use glowkit::interactions::PetalDissolve;

ui.add(PetalDissolve::new("Ember").size(72.0));

Prefer to own the code? The glowkit CLI copies this component's source into your project, shadcn-style:

cargo install glowkit-cli
glowkit add snap-petal-dissolve

If you know this pattern from Snapblocks, Petal Dissolve is the Rust version: an original egui implementation, not a port, that runs natively and in WebAssembly.

About Petal Dissolve

Petal Dissolve is one of 57 components in glowkit's Text Animations category. It lives in the glowkit-interactions crate, enabled by the interactions feature of glowkit (on by default). It reads its colors from the active glowkit theme, so it matches the rest of your app in light, dark or a custom brand theme, and every color, size and timing has a setter to override it.

Per-glyph text effects drawn straight into egui: shimmering and gradient text, blur and split reveals, decrypting and scrambling characters, typewriters, rotating words, counters that roll to a value, glitch, wave and proximity effects. Each one is a single widget you add with ui.add().
