Web Search

An agent's research trail: queries and opened pages hung off a curved guide, with result counts and overlapping site marks, streaming in under a shimmering Working timer.

Usage

Add glowkit next to eframe:

cargo add glowkit eframe

Then draw it inside any egui Ui:

use glowkit::prelude::*;
use glowkit::interactions::{BoardWebSearch, BoardSearchStep};

ui.add(BoardWebSearch::new(vec![
    BoardSearchStep::query("component library pricing", 5).sites(&["reddit", "github"]),
    BoardSearchStep::page("Pricing · Example", "example.com"),
]).progress(1.5));

Prefer to own the code? The glowkit CLI copies this component's source into your project, shadcn-style:

cargo install glowkit-cli
glowkit add board-web-search

Equivalent to

If you know this pattern from BoardUI, Web Search is the Rust version: an original egui implementation, not a port, that runs natively and in WebAssembly.

About Web Search

Web Search is one of 85 components in glowkit's AI category. It lives in the glowkit-interactions crate, enabled by the interactions feature of glowkit (on by default). It reads its colors from the active glowkit theme, so it matches the rest of your app in light, dark or a custom brand theme, and every color, size and timing has a setter to override it.

Everything an AI app needs on screen: streaming Markdown chat, prompt inputs with attachments, reasoning and chain-of-thought panels, tool calls with live arguments, approvals, diff review, traces, agent trees, run monitors, cost and context meters, voice orbs and MCP server managers. Pair them with glowkit-stream to drive them from a real AG-UI, Vercel AI SDK, ACP, rig or OpenAI-compatible stream.
