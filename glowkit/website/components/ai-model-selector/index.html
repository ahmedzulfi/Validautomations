Model Selector & Checkpoint

A model picker pill with provider badges and a dropdown, plus a "Restore checkpoint" conversation divider.

Category AICrate glowkit-aiFeature aiegui 0.37
Try it liveMore AI

Usage

Add glowkit next to eframe:

cargo add glowkit eframe

Then draw it inside any egui Ui:

use glowkit::prelude::*;
use glowkit::ai::{ModelSelector, Checkpoint};

ui.add(ModelSelector::new(&models, &mut selected));
if ui.add(Checkpoint::new().time("2 min ago")).clicked() { restore(); }

Prefer to own the code? The glowkit CLI copies this component's source into your project, shadcn-style:

cargo install glowkit-cli
glowkit add ai-model-selector

Equivalent to

If you know this pattern from Vercel AI Elements, prompt-kit, assistant-ui and ElevenLabs UI, Model Selector & Checkpoint is the Rust version: an original egui implementation, not a port, that runs natively and in WebAssembly.

About Model Selector & Checkpoint

Model Selector & Checkpoint is one of 84 components in glowkit's AI category. It lives in the glowkit-ai crate, enabled by the ai feature of glowkit (on by default). It reads its colors from the active glowkit theme, so it matches the rest of your app in light, dark or a custom brand theme, and every color, size and timing has a setter to override it.

Everything an AI app needs on screen: streaming Markdown chat, prompt inputs with attachments, reasoning and chain-of-thought panels, tool calls with live arguments, approvals, diff review, traces, agent trees, run monitors, cost and context meters, voice orbs and MCP server managers. Pair them with glowkit-stream to drive them from a real AG-UI, Vercel AI SDK, ACP, rig or OpenAI-compatible stream.
