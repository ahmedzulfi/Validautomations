Thread List Sidebar

Conversation sidebar with search highlighting, pinned and date groups, inline rename and a collapsible archive.

Category AICrate glowkit-agentsFeature agentsegui 0.37
Try it liveMore AI

Usage

Add glowkit next to eframe:

cargo add glowkit eframe

Then draw it inside any egui Ui:

use glowkit::prelude::*;
use glowkit::agents::{ThreadListState, ThreadEntry, ThreadListSidebar};

let mut st = ThreadListState { entries: vec![ThreadEntry::new("Q3 deck", "Today").pinned()], ..Default::default() };
let out = ThreadListSidebar::new(&mut st).height(420.0).show(ui);
if let Some(i) = out.opened { open_thread(i); }

Prefer to own the code? The glowkit CLI copies this component's source into your project, shadcn-style:

cargo install glowkit-cli
glowkit add asst-thread-list

About Thread List Sidebar

Thread List Sidebar is one of 84 components in glowkit's AI category. It lives in the glowkit-agents crate, enabled by the agents feature of glowkit (on by default). It reads its colors from the active glowkit theme, so it matches the rest of your app in light, dark or a custom brand theme, and every color, size and timing has a setter to override it.

Everything an AI app needs on screen: streaming Markdown chat, prompt inputs with attachments, reasoning and chain-of-thought panels, tool calls with live arguments, approvals, diff review, traces, agent trees, run monitors, cost and context meters, voice orbs and MCP server managers. Pair them with glowkit-stream to drive them from a real AG-UI, Vercel AI SDK, ACP, rig or OpenAI-compatible stream.
