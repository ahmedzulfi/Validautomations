Text Animations

Highlight Text

Animated emphasis drawn onto a phrase: marker swipe, underline, box, hand-drawn circle or strike-through.

Category Text AnimationsCrate glowkit-textFeature textegui 0.37
Try it liveMore Text Animations

Usage

Add glowkit next to eframe:

cargo add glowkit eframe

Then draw it inside any egui Ui:

use glowkit::prelude::*;
use glowkit::text::{HighlightText, HighlightStyle};

ui.add(HighlightText::new("Everything is a copy, of a copy, of a copy.")
    .phrase("copy, of a copy")
    .size(36.0));
ui.add(HighlightText::new("circled").style(HighlightStyle::Circle));

Prefer to own the code? The glowkit CLI copies this component's source into your project, shadcn-style:

cargo install glowkit-cli
glowkit add highlight-text

About Highlight Text

Highlight Text is one of 57 components in glowkit's Text Animations category. It lives in the glowkit-text crate, enabled by the text feature of glowkit (on by default). It reads its colors from the active glowkit theme, so it matches the rest of your app in light, dark or a custom brand theme, and every color, size and timing has a setter to override it.

Per-glyph text effects drawn straight into egui: shimmering and gradient text, blur and split reveals, decrypting and scrambling characters, typewriters, rotating words, counters that roll to a value, glitch, wave and proximity effects. Each one is a single widget you add with ui.add().
