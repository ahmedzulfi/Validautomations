Calendar & Date Picker

Month grids with today, single and range selection and a sliding month transition; plus popover date pickers.

Category Inputs & FormsCrate glowkit-componentsFeature componentsegui 0.37
Try it liveMore Inputs & Forms

Usage

Add glowkit next to eframe:

cargo add glowkit eframe

Then draw it inside any egui Ui:

use glowkit::prelude::*;
use glowkit::components::{Calendar, DatePicker, CalendarDate};

ui.add(Calendar::new(&mut day).today(today));
ui.add(Calendar::range(&mut from, &mut to).months(2));
ui.add(DatePicker::new(&mut due));
ui.add(DatePicker::range(&mut from, &mut to));

Prefer to own the code? The glowkit CLI copies this component's source into your project, shadcn-style:

cargo install glowkit-cli
glowkit add calendar

Equivalent to

If you know this pattern from shadcn/ui, Origin UI and Kibo UI, Calendar & Date Picker is the Rust version: an original egui implementation, not a port, that runs natively and in WebAssembly.

About Calendar & Date Picker

Calendar & Date Picker is one of 13 components in glowkit's Inputs & Forms category. It lives in the glowkit-components crate, enabled by the components feature of glowkit (on by default). It reads its colors from the active glowkit theme, so it matches the rest of your app in light, dark or a custom brand theme, and every color, size and timing has a setter to override it.

Form controls with motion: one-time-code inputs with autofill, ratings, color pickers, calendars, file dropzones, vanishing inputs, day/night switches and availability schedulers.
