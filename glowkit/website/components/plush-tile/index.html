Plush Tile

An app-icon tile covered in thousands of short combed strands that carry a mark in the pile; the fur parts under the pointer and stirs in a breeze.

Category Micro-interactionsCrate glowkit-interactionsFeature interactionsegui 0.37
Try it liveMore Micro-interactions

Usage

Add glowkit next to eframe:

cargo add glowkit eframe

Then draw it inside any egui Ui:

use glowkit::prelude::*;
use glowkit::interactions::{PlushTile, PlushMark};

ui.add(PlushTile::new().mark(PlushMark::Ring).size(220.0));

Prefer to own the code? The glowkit CLI copies this component's source into your project, shadcn-style:

cargo install glowkit-cli
glowkit add plush-tile

About Plush Tile

Plush Tile is one of 71 components in glowkit's Micro-interactions category. It lives in the glowkit-interactions crate, enabled by the interactions feature of glowkit (on by default). It reads its colors from the active glowkit theme, so it matches the rest of your app in light, dark or a custom brand theme, and every color, size and timing has a setter to override it.

Small, physical details that make an app feel finished: liquid toggles, slide-to-confirm, swipe actions, reorderable lists, pull to refresh, emoji reactions, rolling counters, success checks, error shakes and notification badges, each tuned with springs.
