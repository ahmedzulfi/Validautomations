Link Preview Result

Unfurled links as cards: cover image with a slow hover zoom, favicon and domain, title and description.

Category AICrate glowkit-agentsFeature agentsegui 0.37
Try it liveMore AI

Usage

Add glowkit next to eframe:

cargo add glowkit eframe

Then draw it inside any egui Ui:

use glowkit::prelude::*;
use glowkit::agents::LinkPreviewResult;

if ui.add(LinkPreviewResult::new("fieldnotes.dev", "Designing calm agent interfaces", "Why quiet UI earns trust.")).clicked() {
    // open the link
}

Prefer to own the code? The glowkit CLI copies this component's source into your project, shadcn-style:

cargo install glowkit-cli
glowkit add asst-tool-link

Equivalent to

If you know this pattern from Tool UI and assistant-ui, Link Preview Result is the Rust version: an original egui implementation, not a port, that runs natively and in WebAssembly.

About Link Preview Result

Link Preview Result is one of 85 components in glowkit's AI category. It lives in the glowkit-agents crate, enabled by the agents feature of glowkit (on by default). It reads its colors from the active glowkit theme, so it matches the rest of your app in light, dark or a custom brand theme, and every color, size and timing has a setter to override it.

Everything an AI app needs on screen: streaming Markdown chat, prompt inputs with attachments, reasoning and chain-of-thought panels, tool calls with live arguments, approvals, diff review, traces, agent trees, run monitors, cost and context meters, voice orbs and MCP server managers. Pair them with glowkit-stream to drive them from a real AG-UI, Vercel AI SDK, ACP, rig or OpenAI-compatible stream.
