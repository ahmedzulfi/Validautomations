Liquid Toggle

A switch whose droplet stretches as it slides across the track and snaps round at the end.

Category Micro-interactionsCrate glowkit-effectsFeature effectsegui 0.37
Try it liveMore Micro-interactions

Usage

Add glowkit next to eframe:

cargo add glowkit eframe

Then draw it inside any egui Ui:

use glowkit::prelude::*;
use glowkit::effects::LiquidToggle;

let mut on = false;
ui.add(LiquidToggle::new(&mut on).speed(50.0).stretch(36.0));

Prefer to own the code? The glowkit CLI copies this component's source into your project, shadcn-style:

cargo install glowkit-cli
glowkit add liq-toggle

Equivalent to

If you know this pattern from Bencho, Liquid Toggle is the Rust version: an original egui implementation, not a port, that runs natively and in WebAssembly.

About Liquid Toggle

Liquid Toggle is one of 71 components in glowkit's Micro-interactions category. It lives in the glowkit-effects crate, enabled by the effects feature of glowkit (on by default). It reads its colors from the active glowkit theme, so it matches the rest of your app in light, dark or a custom brand theme, and every color, size and timing has a setter to override it.

Small, physical details that make an app feel finished: liquid toggles, slide-to-confirm, swipe actions, reorderable lists, pull to refresh, emoji reactions, rolling counters, success checks, error shakes and notification badges, each tuned with springs.
