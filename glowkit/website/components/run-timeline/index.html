Run Timeline

An agent run as a quiet trail of steps: tool calls with live spinners, finished steps that fold, a failed step with its error and Retry, and a light running down the rail.

Category AICrate glowkit-agentsFeature agentsegui 0.37
Try it liveMore AI

Usage

Add glowkit next to eframe:

cargo add glowkit eframe

Then draw it inside any egui Ui:

use glowkit::prelude::*;
use glowkit::agents::{TimelineStep, RunState, StepTool, RunTimeline};
use glowkit::components::Icon;

let steps = vec![
    TimelineStep::new("Investigate the failed deploy", RunState::Done).secs(4.0)
        .tool(StepTool::new("read_logs", Icon::Terminal, RunState::Done).secs(1.2)),
    TimelineStep::new("Install the missing dependency", RunState::Running)
        .tool(StepTool::new("shell", Icon::Terminal, RunState::Running).detail("pnpm add zod")),
];
let out = RunTimeline::new("Fix the failing deploy", &steps).show(ui);

Prefer to own the code? The glowkit CLI copies this component's source into your project, shadcn-style:

cargo install glowkit-cli
glowkit add run-timeline

About Run Timeline

Run Timeline is one of 85 components in glowkit's AI category. It lives in the glowkit-agents crate, enabled by the agents feature of glowkit (on by default). It reads its colors from the active glowkit theme, so it matches the rest of your app in light, dark or a custom brand theme, and every color, size and timing has a setter to override it.

Everything an AI app needs on screen: streaming Markdown chat, prompt inputs with attachments, reasoning and chain-of-thought panels, tool calls with live arguments, approvals, diff review, traces, agent trees, run monitors, cost and context meters, voice orbs and MCP server managers. Pair them with glowkit-stream to drive them from a real AG-UI, Vercel AI SDK, ACP, rig or OpenAI-compatible stream.

More in AI

Plan Board

AI

An agent's plan as a four-column board: step cards with agent, tool and live progress lift and glide from Planned to Running to Review to Done.

Error Recovery Card

AI

A failed step waiting for you: error code and message, attempt pips, last log lines, the agent's suggested fix, Retry / Skip / Abort and an auto-retry countdown ring.

Agent Tree

AI

An orchestrator and its sub-agents as a live tree of cards: status, model, task, cost and time on each, lights running along connectors to working agents, branches that fold.

Approval Queue

AI

Pending tool calls to approve, deny or edit, with risk badges, the exact command, waiting time, batch actions and rows that resolve and fold away.

Live agent stream

AI

A recorded agent run replayed through the real stream reducer: reasoning, streamed Markdown, tool calls with live arguments, an approval, a plan and an error. Switch between AG-UI, Vercel AI SDK and ACP-style sources.

Diff Review

AI

An agent's file changes for review: unified or side-by-side diff, per-hunk accept and reject that fold the hunk, J/K/Y/N keys, and an apply footer.
