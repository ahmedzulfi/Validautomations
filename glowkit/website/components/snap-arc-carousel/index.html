Arc Carousel

Cards riding a very large circle, the focused one upright at the apex and the rest tilted tangent to the curve.

Category 3DCrate glowkit-interactionsFeature interactionsegui 0.37
Try it liveMore 3D

Usage

Add glowkit next to eframe:

cargo add glowkit eframe

Then draw it inside any egui Ui:

use glowkit::prelude::*;
use glowkit::interactions::{ArcItem, ArcCarousel};

let items = vec![ArcItem::new("Old Quarter", "Lanes that bend toward the river."), /* ... */];
ui.add(ArcCarousel::new(&items).curve(1.0).autoplay(2.8));

Prefer to own the code? The glowkit CLI copies this component's source into your project, shadcn-style:

cargo install glowkit-cli
glowkit add snap-arc-carousel

About Arc Carousel

Arc Carousel is one of 34 components in glowkit's 3D category. It lives in the glowkit-interactions crate, enabled by the interactions feature of glowkit (on by default). It reads its colors from the active glowkit theme, so it matches the rest of your app in light, dark or a custom brand theme, and every color, size and timing has a setter to override it.

A software 3D renderer that draws lit, depth-sorted meshes straight into egui: model viewers with orbit controls, globes, particle clouds that morph between shapes, terrains, voxel text, 3D charts and carousels. No wgpu boilerplate, and it runs in WebAssembly too.
