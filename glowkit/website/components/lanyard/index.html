Usage

Add glowkit next to eframe:

cargo add glowkit eframe

Then draw it inside any egui Ui:

use glowkit::prelude::*;
use glowkit::motion::Lanyard;

Lanyard::new(id).card_size(vec2(170.0, 220.0)).rope_length(150.0).show(ui, |ui| {
    ui.heading("Alex Rivera");
    ui.label("Motion Engineer");
});

Prefer to own the code? The glowkit CLI copies this component's source into your project, shadcn-style:

cargo install glowkit-cli
glowkit add lanyard

If you know this pattern from React Bits, Lanyard is the Rust version: an original egui implementation, not a port, that runs natively and in WebAssembly.

About Lanyard

Lanyard is one of 17 components in glowkit's Motion Engine category. It lives in the glowkit-motion crate, enabled by the motion feature of glowkit (on by default). It reads its colors from the active glowkit theme, so it matches the rest of your app in light, dark or a custom brand theme, and every color, size and timing has a setter to override it.

The engine under every glowkit animation, exposed for your own UI: springs, keyframes, GSAP-style timelines, variants with stagger, enter and exit presence, FLIP layout animation, shared elements, drag with inertia and snapping, scroll-linked values, motion paths and shape morphing.
