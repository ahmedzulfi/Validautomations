Logo Cloud

Trust logos as a row, a bordered grid with hover, or two marquee rows moving in opposite directions.

Category BlocksCrate glowkit-templatesFeature templatesegui 0.37
Try it liveMore Blocks

Usage

Add glowkit next to eframe:

cargo add glowkit eframe

Then draw it inside any egui Ui:

use glowkit::prelude::*;
use glowkit::templates::{LogoCloudSection, LogoCloudLayout};

LogoCloudSection::new().layout(LogoCloudLayout::Marquee).show(ui);

Prefer to own the code? The glowkit CLI copies this component's source into your project, shadcn-style:

cargo install glowkit-cli
glowkit add logo-cloud

Equivalent to

If you know this pattern from MVP Blocks, Tailark and Magic UI, Logo Cloud is the Rust version: an original egui implementation, not a port, that runs natively and in WebAssembly.

About Logo Cloud

Logo Cloud is one of 28 components in glowkit's Blocks category. It lives in the glowkit-templates crate, enabled by the templates feature of glowkit (on by default). It reads its colors from the active glowkit theme, so it matches the rest of your app in light, dark or a custom brand theme, and every color, size and timing has a setter to override it.

Ready-made sections you compose into screens: heroes, feature grids and bento layouts, pricing, testimonials, FAQs, teams, changelogs, logo clouds and device mockups.
