Pricing Page

Pricing page with billing toggle, beam-highlighted plan, logo cloud, comparison table, billing FAQ and CTA.

Category TemplatesCrate glowkit-templatesFeature templatesegui 0.37
Try it liveMore Templates

Usage

Add glowkit next to eframe:

cargo add glowkit eframe

Then draw it inside any egui Ui:

use glowkit::prelude::*;
use glowkit::templates::{PricingPage, PricingTier};

let r = PricingPage::new("Glowkit").tiers(PricingTier::defaults()).show(ui);
if r.clicked("Pro") { /* checkout */ }

Prefer to own the code? The glowkit CLI copies this component's source into your project, shadcn-style:

cargo install glowkit-cli
glowkit add pricing-page

If you know this pattern from MVP Blocks and shadcnblocks, Pricing Page is the Rust version: an original egui implementation, not a port, that runs natively and in WebAssembly.

About Pricing Page

Pricing Page is one of 43 components in glowkit's Templates category. It lives in the glowkit-templates crate, enabled by the templates feature of glowkit (on by default). It reads its colors from the active glowkit theme, so it matches the rest of your app in light, dark or a custom brand theme, and every color, size and timing has a setter to override it.

Complete screens you can start from: landing, pricing, auth, onboarding and error pages, plus working app templates such as an analytics dashboard, CRM, e-commerce admin, mail client, team chat, AI assistant, agent session manager, local LLM chat, trading terminal and profiler.
