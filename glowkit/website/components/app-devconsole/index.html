Developer Console

Usage page with KPI tiles, request and error charts and a 90-day uptime tracker; API keys with a reveal-once create dialog and revoke confirmation; a live log stream.

Category TemplatesCrate glowkit-templatesFeature templatesegui 0.37
Try it liveMore Templates

Usage

Add glowkit next to eframe:

cargo add glowkit eframe

Then draw it inside any egui Ui:

use glowkit::prelude::*;
use glowkit::templates::DevConsoleApp;

let mut app = DevConsoleApp::default();
app.route = "keys".into(); // "usage" | "keys" | "logs"
app.show(ui);

Prefer to own the code? The glowkit CLI copies this component's source into your project, shadcn-style:

cargo install glowkit-cli
glowkit add app-devconsole

Equivalent to

If you know this pattern from Stripe, Vercel and Supabase, Developer Console is the Rust version: an original egui implementation, not a port, that runs natively and in WebAssembly.

About Developer Console

Developer Console is one of 43 components in glowkit's Templates category. It lives in the glowkit-templates crate, enabled by the templates feature of glowkit (on by default). It reads its colors from the active glowkit theme, so it matches the rest of your app in light, dark or a custom brand theme, and every color, size and timing has a setter to override it.

Complete screens you can start from: landing, pricing, auth, onboarding and error pages, plus working app templates such as an analytics dashboard, CRM, e-commerce admin, mail client, team chat, AI assistant, agent session manager, local LLM chat, trading terminal and profiler.
