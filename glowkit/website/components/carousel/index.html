Carousel

Drag or swipe between items that snap into place on a spring; neighbors peek in and dots track position.

Category Motion & LayoutCrate glowkit-effectsFeature effectsegui 0.37
Try it liveMore Motion & Layout

Usage

Add glowkit next to eframe:

cargo add glowkit eframe

Then draw it inside any egui Ui:

use glowkit::prelude::*;
use glowkit::effects::Carousel;

Carousel::new(5).autoplay(3.0).looping(true).show(ui, |ui, i| {
    ui.heading(format!("Slide {i}"));
});

Prefer to own the code? The glowkit CLI copies this component's source into your project, shadcn-style:

cargo install glowkit-cli
glowkit add carousel

Equivalent to

If you know this pattern from React Bits, Motion Primitives, Aceternity UI, shadcn/ui and Bencho, Carousel is the Rust version: an original egui implementation, not a port, that runs natively and in WebAssembly.

About Carousel

Carousel is one of 46 components in glowkit's Motion & Layout category. It lives in the glowkit-effects crate, enabled by the effects feature of glowkit (on by default). It reads its colors from the active glowkit theme, so it matches the rest of your app in light, dark or a custom brand theme, and every color, size and timing has a setter to override it.

Layout pieces that move: a magnifying dock, marquees, animated lists, card stacks and swaps, carousels and coverflow, expandable cards, masonry, parallax heroes, sticky scroll reveals and animated beams between elements.
