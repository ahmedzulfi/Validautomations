Modal Open Close

A dialog pops in from 96% while fading on a long smooth curve, and leaves in about half the time.

Category Micro-interactionsCrate glowkit-interactionsFeature interactionsegui 0.37
Try it liveMore Micro-interactions

Usage

Add glowkit next to eframe:

cargo add glowkit eframe

Then draw it inside any egui Ui:

use glowkit::prelude::*;
use glowkit::interactions::PopModal;

ui.add(PopModal::new(open)
    .title("Delete project?")
    .body("This removes the project and its files for everyone.")
    .actions("Cancel", "Delete"));

Prefer to own the code? The glowkit CLI copies this component's source into your project, shadcn-style:

cargo install glowkit-cli
glowkit add tx-modal-open-close

Equivalent to

If you know this pattern from Transitions.dev, Modal Open Close is the Rust version: an original egui implementation, not a port, that runs natively and in WebAssembly.

About Modal Open Close

Modal Open Close is one of 71 components in glowkit's Micro-interactions category. It lives in the glowkit-interactions crate, enabled by the interactions feature of glowkit (on by default). It reads its colors from the active glowkit theme, so it matches the rest of your app in light, dark or a custom brand theme, and every color, size and timing has a setter to override it.

Small, physical details that make an app feel finished: liquid toggles, slide-to-confirm, swipe actions, reorderable lists, pull to refresh, emoji reactions, rolling counters, success checks, error shakes and notification badges, each tuned with springs.
