Wake Slider

A range made of thin bars with no thumb; drag fast and the bars you sweep past spring up in a wake behind the hand.

Category Micro-interactionsCrate glowkit-effectsFeature effectsegui 0.37
Try it liveMore Micro-interactions

Usage

Add glowkit next to eframe:

cargo add glowkit eframe

Then draw it inside any egui Ui:

use glowkit::prelude::*;
use glowkit::effects::WakeSlider;

let mut value = 50.0;
ui.add(WakeSlider::new(&mut value).bars(36).wake(60.0));

Prefer to own the code? The glowkit CLI copies this component's source into your project, shadcn-style:

cargo install glowkit-cli
glowkit add wake-slider

Equivalent to

If you know this pattern from Bencho, Wake Slider is the Rust version: an original egui implementation, not a port, that runs natively and in WebAssembly.

About Wake Slider

Wake Slider is one of 71 components in glowkit's Micro-interactions category. It lives in the glowkit-effects crate, enabled by the effects feature of glowkit (on by default). It reads its colors from the active glowkit theme, so it matches the rest of your app in light, dark or a custom brand theme, and every color, size and timing has a setter to override it.

Small, physical details that make an app feel finished: liquid toggles, slide-to-confirm, swipe actions, reorderable lists, pull to refresh, emoji reactions, rolling counters, success checks, error shakes and notification badges, each tuned with springs.
