3D Viewport

The software 3D engine: meshes, materials (smooth, flat, toon, matcap, normal, wireframe, glow), lights, shadows, grid and 3D text, depth-sorted into egui meshes. Drag to orbit.

Category 3DCrate glowkit-3dFeature three-degui 0.37
Try it liveMore 3D

Usage

Add glowkit next to eframe:

cargo add glowkit eframe

Then draw it inside any egui Ui:

use glowkit::prelude::*;
use glowkit::three_d::{Viewport3D, OrbitControls, Mesh, Material, Transform, Vec3, vec3};

Viewport3D::new("scene")
    .height(360.0)
    .controls(OrbitControls::new().distance(9.0).auto_rotate(0.2))
    .show(ui, |scene, ctx| {
        let knot = ctx.mesh("knot", || Mesh::torus_knot(2, 3, 0.8, 0.2, 120, 10));
        let mat = Material::smooth(ctx.theme.accent).specular(0.6).rim(0.3);
        scene.shadow(vec3(0.0, -1.0, 0.0), 0.8, Color32::from_black_alpha(120));
        scene.draw(&knot, Transform::IDENTITY.with_euler(0.0, ctx.time, 0.0), &mat);
        scene.text("Hello", vec3(0.0, -1.0, 1.0), Vec3::X, -Vec3::Z, 0.3, ctx.theme.foreground, Align2::CENTER_CENTER);
    });

Prefer to own the code? The glowkit CLI copies this component's source into your project, shadcn-style:

cargo install glowkit-cli
glowkit add viewport-3d

About 3D Viewport

3D Viewport is one of 34 components in glowkit's 3D category. It lives in the glowkit-3d crate, enabled by the three-d feature of glowkit (on by default). It reads its colors from the active glowkit theme, so it matches the rest of your app in light, dark or a custom brand theme, and every color, size and timing has a setter to override it.

A software 3D renderer that draws lit, depth-sorted meshes straight into egui: model viewers with orbit controls, globes, particle clouds that morph between shapes, terrains, voxel text, 3D charts and carousels. No wgpu boilerplate, and it runs in WebAssembly too.
