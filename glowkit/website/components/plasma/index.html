Plasma

Classic demoscene plasma: interfering sine fields mapped to a glowing, looping palette.

Category BackgroundsCrate glowkit-backgroundsFeature backgroundsegui 0.37
Try it liveMore Backgrounds

Usage

Add glowkit next to eframe:

cargo add glowkit eframe

Then draw it inside any egui Ui:

use glowkit::prelude::*;
use glowkit::backgrounds::Plasma;

ui.add(Plasma::new());
ui.add(Plasma::new().colors(&palettes::NEON).scale(1.4));

Prefer to own the code? The glowkit CLI copies this component's source into your project, shadcn-style:

cargo install glowkit-cli
glowkit add plasma

Equivalent to

If you know this pattern from React Bits, Plasma is the Rust version: an original egui implementation, not a port, that runs natively and in WebAssembly.

About Plasma

Plasma is one of 63 components in glowkit's Backgrounds category. It lives in the glowkit-backgrounds crate, enabled by the backgrounds feature of glowkit (on by default). It reads its colors from the active glowkit theme, so it matches the rest of your app in light, dark or a custom brand theme, and every color, size and timing has a setter to override it.

Full-panel animated backgrounds built from vertex-colored meshes, so they stay cheap on the GPU: aurora, silk, plasma, particles, meteors, starfields, beams, grids, waves, liquid metal and dozens more. Paint one behind any egui layout with a single call.
