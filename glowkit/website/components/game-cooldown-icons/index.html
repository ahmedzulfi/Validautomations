Cooldown Icons

Ability slots with a radial cooldown sweep, a bright hand on the edge and seconds left; coming off cooldown flashes white, pops on a spring and throws a ring of sparks.

Usage

Add glowkit next to eframe:

cargo add glowkit eframe

Then draw it inside any egui Ui:

use glowkit::prelude::*;
use glowkit::interactions::{GameCooldownIcon, GameIcon};

ui.add(GameCooldownIcon::new(GameIcon::Fire, remaining, 8.0).key("Q").charges(2));

Prefer to own the code? The glowkit CLI copies this component's source into your project, shadcn-style:

cargo install glowkit-cli
glowkit add game-cooldown-icons

About Cooldown Icons

Cooldown Icons is one of 25 components in glowkit's Game UI category. It lives in the glowkit-interactions crate, enabled by the interactions feature of glowkit (on by default). It reads its colors from the active glowkit theme, so it matches the rest of your app in light, dark or a custom brand theme, and every color, size and timing has a setter to override it.

Game interface pieces that take plain game state each frame: main and pause menus, HUD bars with damage trails, minimaps, ammo counters, cooldown icons, hotbars, inventories with tooltips, skill trees, dialogue boxes, quest trackers, loot and achievement popups, kill feeds and scoreboards. Works in Bevy through bevy_egui.
