Shared Layout Background

One soft background slides and resizes between list rows or nav links under the pointer, instead of each item lighting up on its own.

Category NavigationCrate glowkit-interactionsFeature interactionsegui 0.37
Try it liveMore Navigation

Usage

Add glowkit next to eframe:

cargo add glowkit eframe

Then draw it inside any egui Ui:

use glowkit::prelude::*;
use glowkit::interactions::SharedLayoutBg;

let clicked = SharedLayoutBg::new()
    .item("Inbox", "12 unread threads, 3 mentions today.")
    .item("Drafts", "4 posts waiting for a final pass.")
    .show(ui);
SharedLayoutBg::new().horizontal(true).item("Home", "").item("Docs", "").show(ui);

Prefer to own the code? The glowkit CLI copies this component's source into your project, shadcn-style:

cargo install glowkit-cli
glowkit add beui-shared-layout-bg

Equivalent to

If you know this pattern from beUI, Shared Layout Background is the Rust version: an original egui implementation, not a port, that runs natively and in WebAssembly.

About Shared Layout Background

Shared Layout Background is one of 18 components in glowkit's Navigation category. It lives in the glowkit-interactions crate, enabled by the interactions feature of glowkit (on by default). It reads its colors from the active glowkit theme, so it matches the rest of your app in light, dark or a custom brand theme, and every color, size and timing has a setter to override it.

Menus and navigation that move with intent: bubble, pill, gooey and staggered menus, card navs, floating and resizable navbars, sidebars, command palettes, tables of contents and morphing tab bars.
