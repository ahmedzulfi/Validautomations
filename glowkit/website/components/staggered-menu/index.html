Staggered Menu

A full-height side menu: colored layers sweep in, staggered, followed by a panel of huge numbered links rising into place.

Category NavigationCrate glowkit-effectsFeature effectsegui 0.37
Try it liveMore Navigation

Usage

Add glowkit next to eframe:

cargo add glowkit eframe

Then draw it inside any egui Ui:

use glowkit::prelude::*;
use glowkit::effects::StaggeredMenu;

let r = StaggeredMenu::new(&["Home", "About", "Services", "Contact"])
    .socials(&["Twitter", "GitHub", "LinkedIn"])
    .show(ui, |ui| { ui.heading("Your page"); });
if let Some(i) = r.inner { /* ... */ }

Prefer to own the code? The glowkit CLI copies this component's source into your project, shadcn-style:

cargo install glowkit-cli
glowkit add staggered-menu

If you know this pattern from React Bits, Staggered Menu is the Rust version: an original egui implementation, not a port, that runs natively and in WebAssembly.

About Staggered Menu

Staggered Menu is one of 18 components in glowkit's Navigation category. It lives in the glowkit-effects crate, enabled by the effects feature of glowkit (on by default). It reads its colors from the active glowkit theme, so it matches the rest of your app in light, dark or a custom brand theme, and every color, size and timing has a setter to override it.

Menus and navigation that move with intent: bubble, pill, gooey and staggered menus, card navs, floating and resizable navbars, sidebars, command palettes, tables of contents and morphing tab bars.
