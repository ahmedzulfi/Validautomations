Prism Beam

A glass prism that refracts a white beam into a rainbow fan with real Snell's law; drag to aim the light and watch the spectrum sweep.

Category 3DCrate glowkit-interactionsFeature interactionsegui 0.37
Try it liveMore 3D

Usage

Add glowkit next to eframe:

cargo add glowkit eframe

Then draw it inside any egui Ui:

use glowkit::prelude::*;
use glowkit::interactions::PrismBeam;

ui.add(PrismBeam::new().dispersion(60.0).glow(50.0));

Prefer to own the code? The glowkit CLI copies this component's source into your project, shadcn-style:

cargo install glowkit-cli
glowkit add prism-beam

If you know this pattern from ObsidianUI, Prism Beam is the Rust version: an original egui implementation, not a port, that runs natively and in WebAssembly.

About Prism Beam

Prism Beam is one of 34 components in glowkit's 3D category. It lives in the glowkit-interactions crate, enabled by the interactions feature of glowkit (on by default). It reads its colors from the active glowkit theme, so it matches the rest of your app in light, dark or a custom brand theme, and every color, size and timing has a setter to override it.

A software 3D renderer that draws lit, depth-sorted meshes straight into egui: model viewers with orbit controls, globes, particle clouds that morph between shapes, terrains, voxel text, 3D charts and carousels. No wgpu boilerplate, and it runs in WebAssembly too.
