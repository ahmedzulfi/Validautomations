Parallax Slider

An endless strip of tall frames: drag, flick or scroll and each picture drifts against the motion inside its frame; titles rise on hover once still.

Category Motion & LayoutCrate glowkit-interactionsFeature interactionsegui 0.37
Try it liveMore Motion & Layout

Usage

Add glowkit next to eframe:

cargo add glowkit eframe

Then draw it inside any egui Ui:

use glowkit::prelude::*;
use glowkit::interactions::ParallaxSlider;

ui.add(ParallaxSlider::new().depth(60.0).friction(50.0));

Prefer to own the code? The glowkit CLI copies this component's source into your project, shadcn-style:

cargo install glowkit-cli
glowkit add parallax-slider

Equivalent to

If you know this pattern from ObsidianUI, Parallax Slider is the Rust version: an original egui implementation, not a port, that runs natively and in WebAssembly.

About Parallax Slider

Parallax Slider is one of 46 components in glowkit's Motion & Layout category. It lives in the glowkit-interactions crate, enabled by the interactions feature of glowkit (on by default). It reads its colors from the active glowkit theme, so it matches the rest of your app in light, dark or a custom brand theme, and every color, size and timing has a setter to override it.

Layout pieces that move: a magnifying dock, marquees, animated lists, card stacks and swaps, carousels and coverflow, expandable cards, masonry, parallax heroes, sticky scroll reveals and animated beams between elements.
