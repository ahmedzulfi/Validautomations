Testimonials

Customer quotes as a card grid, two marquee rows, or one featured quote cycling with progress dots.

Category BlocksCrate glowkit-templatesFeature templatesegui 0.37
Try it liveMore Blocks

Usage

Add glowkit next to eframe:

cargo add glowkit eframe

Then draw it inside any egui Ui:

use glowkit::prelude::*;
use glowkit::templates::{TestimonialsSection, TestimonialsLayout};

TestimonialsSection::new("Loved by builders").layout(TestimonialsLayout::Marquee).show(ui);

Prefer to own the code? The glowkit CLI copies this component's source into your project, shadcn-style:

cargo install glowkit-cli
glowkit add testimonials-section

If you know this pattern from MVP Blocks, Tailark, Magic UI and Aceternity, Testimonials is the Rust version: an original egui implementation, not a port, that runs natively and in WebAssembly.

About Testimonials

Testimonials is one of 28 components in glowkit's Blocks category. It lives in the glowkit-templates crate, enabled by the templates feature of glowkit (on by default). It reads its colors from the active glowkit theme, so it matches the rest of your app in light, dark or a custom brand theme, and every color, size and timing has a setter to override it.

Ready-made sections you compose into screens: heroes, feature grids and bento layouts, pricing, testimonials, FAQs, teams, changelogs, logo clouds and device mockups.
