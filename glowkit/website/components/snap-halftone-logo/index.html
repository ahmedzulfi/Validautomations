Halftone Logo

A logo built from a rotated halftone dot screen with a wave of ink rolling through the dots.

Category BackgroundsCrate glowkit-interactionsFeature interactionsegui 0.37
Try it liveMore Backgrounds

Usage

Add glowkit next to eframe:

cargo add glowkit eframe

Then draw it inside any egui Ui:

use glowkit::prelude::*;
use glowkit::interactions::HalftoneLogo;

ui.add(HalftoneLogo::new("lumen").pitch(7.0).angle(20.0).wave(1.0));

Prefer to own the code? The glowkit CLI copies this component's source into your project, shadcn-style:

cargo install glowkit-cli
glowkit add snap-halftone-logo

Equivalent to

If you know this pattern from Snapblocks, Halftone Logo is the Rust version: an original egui implementation, not a port, that runs natively and in WebAssembly.

About Halftone Logo

Halftone Logo is one of 63 components in glowkit's Backgrounds category. It lives in the glowkit-interactions crate, enabled by the interactions feature of glowkit (on by default). It reads its colors from the active glowkit theme, so it matches the rest of your app in light, dark or a custom brand theme, and every color, size and timing has a setter to override it.

Full-panel animated backgrounds built from vertex-colored meshes, so they stay cheap on the GPU: aurora, silk, plasma, particles, meteors, starfields, beams, grids, waves, liquid metal and dozens more. Paint one behind any egui layout with a single call.
