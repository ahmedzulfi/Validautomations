Animated Tooltip

Overlapping avatars; the hovered one lifts and a name tooltip pops above it, swinging with the pointer on a loose spring.

Usage

Add glowkit next to eframe:

cargo add glowkit eframe

Then draw it inside any egui Ui:

use glowkit::prelude::*;
use glowkit::blocks::{Person, AnimatedTooltip};

let team = [Person::new("Sarah Chen", "Product Designer", hex("#8B5CF6"), hex("#EC4899")), /* ... */];
ui.add(AnimatedTooltip::new(&team));

Prefer to own the code? The glowkit CLI copies this component's source into your project, shadcn-style:

cargo install glowkit-cli
glowkit add animated-tooltip

About Animated Tooltip

Animated Tooltip is one of 29 components in glowkit's Cursor & Interaction category. It lives in the glowkit-blocks crate, enabled by the blocks feature of glowkit (on by default). It reads its colors from the active glowkit theme, so it matches the rest of your app in light, dark or a custom brand theme, and every color, size and timing has a setter to override it.

Pointer-driven effects: click sparks and ripples, ribbon, pixel and image trails, smooth and target cursors, magnets, confetti and fireworks, lenses, scratch-to-reveal and before/after compare sliders.
