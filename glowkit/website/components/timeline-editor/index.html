Timeline Editor

Video-editor tracks with thumbnail strips and waveforms: drag clips across tracks, trim either edge with magnetic snapping, scrub the playhead on the zoomable ruler, press space to play.

Category Canvas & EditorsCrate glowkit-canvasFeature canvasegui 0.37
Try it liveMore Canvas & Editors

Usage

Add glowkit next to eframe:

cargo add glowkit eframe

Then draw it inside any egui Ui:

use glowkit::prelude::*;
use glowkit::canvas::{Timeline, Track, ClipKind, Clip, TimelineEditor, TimelineState};

let mut tl = Timeline { fps: 30.0, duration: 90.0, tracks: vec![
    Track::new("V1", ClipKind::Video, vec![Clip::new(1, "Intro.mp4", 0.0, 8.0)]),
    Track::new("A1", ClipKind::Audio, vec![Clip::new(2, "Music.wav", 0.0, 60.0)]),
] };
TimelineEditor::new(&mut tl, &mut state).height(420.0).show(ui);

Prefer to own the code? The glowkit CLI copies this component's source into your project, shadcn-style:

cargo install glowkit-cli
glowkit add timeline-editor

About Timeline Editor

Timeline Editor is one of 13 components in glowkit's Canvas & Editors category. It lives in the glowkit-canvas crate, enabled by the canvas feature of glowkit (on by default). It reads its colors from the active glowkit theme, so it matches the rest of your app in light, dark or a custom brand theme, and every color, size and timing has a setter to override it.

The heavy pieces of creative and developer tools: a React-Flow-style node editor, shader graphs, flowcharts, an infinite canvas and whiteboard, kanban and gantt boards, mind maps, a timeline editor, a data grid, org charts and a signature pad.
