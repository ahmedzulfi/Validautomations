Coach Tip

Feature tips that pop out of their arrow on a spring; drag one and it rubber-bands, fling it and it flies off; then the next tip in the group appears.

Category Overlays & FeedbackCrate glowkit-interactionsFeature interactionsegui 0.37
Try it liveMore Overlays & Feedback

Usage

Add glowkit next to eframe:

cargo add glowkit eframe

Then draw it inside any egui Ui:

use glowkit::prelude::*;
use glowkit::interactions::CoachTip;

ui.add(CoachTip::new("new-note", "Start a note fast", "Tap here any time to begin a new note.").anchor(anchor));
if CoachTip::dismissed(ui.ctx(), "new-note") {
    ui.add(CoachTip::new("share", "Share in one tap", "Send any note to a friend.").anchor(share_anchor));
}

Prefer to own the code? The glowkit CLI copies this component's source into your project, shadcn-style:

cargo install glowkit-cli
glowkit add coach-tip

Equivalent to

If you know this pattern from suiss/ui, Coach Tip is the Rust version: an original egui implementation, not a port, that runs natively and in WebAssembly.

About Coach Tip

Coach Tip is one of 17 components in glowkit's Overlays & Feedback category. It lives in the glowkit-interactions crate, enabled by the interactions feature of glowkit (on by default). It reads its colors from the active glowkit theme, so it matches the rest of your app in light, dark or a custom brand theme, and every color, size and timing has a setter to override it.

Overlays that open and close with springs: toasts, alert dialogs, morphing modals, dynamic-island notifications, guided tours, banners, undo bars, confirm sheets and feedback widgets.
