Grouped page tree, an article with breadcrumbs, callouts and code, a scroll-synced table of contents, prev / next cards and a helpful-or-not prompt.

Usage

Add glowkit next to eframe:

cargo add glowkit eframe

Then draw it inside any egui Ui:

use glowkit::prelude::*;
use glowkit::templates::DocsApp;

let mut app = DocsApp::default();
app.show(ui);

Prefer to own the code? The glowkit CLI copies this component's source into your project, shadcn-style:

cargo install glowkit-cli
glowkit add app-docs

Equivalent to

If you know this pattern from Nextra, Mintlify and shadcn/ui, Docs / Knowledge Base is the Rust version: an original egui implementation, not a port, that runs natively and in WebAssembly.

About Docs / Knowledge Base

Docs / Knowledge Base is one of 43 components in glowkit's Templates category. It lives in the glowkit-templates crate, enabled by the templates feature of glowkit (on by default). It reads its colors from the active glowkit theme, so it matches the rest of your app in light, dark or a custom brand theme, and every color, size and timing has a setter to override it.

Complete screens you can start from: landing, pricing, auth, onboarding and error pages, plus working app templates such as an analytics dashboard, CRM, e-commerce admin, mail client, team chat, AI assistant, agent session manager, local LLM chat, trading terminal and profiler.
