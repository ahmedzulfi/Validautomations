Motion Engine

Shared Element

A thumbnail expands into a detail view and back: the same key used in two places animates between them (layoutId).

Category Motion EngineCrate glowkit-motionFeature motionegui 0.37
Try it liveMore Motion Engine

Usage

Add glowkit next to eframe:

cargo add glowkit eframe

Then draw it inside any egui Ui:

use glowkit::prelude::*;
use glowkit::motion::LayoutAnim;

LayoutAnim::new(id).show(ui, |layout, ui| {
    for (i, album) in albums.iter().enumerate() {
        // the same key in the grid or in the detail view: it flies between them
        let rect = if open == Some(i) { detail_rect } else { grid_rect(i) };
        if layout.item_at(ui, i, rect, |ui| cover(ui, album)).clicked() {
            open = if open == Some(i) { None } else { Some(i) };
        }
    }
});

Prefer to own the code? The glowkit CLI copies this component's source into your project, shadcn-style:

cargo install glowkit-cli
glowkit add shared-element

About Shared Element

Shared Element is one of 17 components in glowkit's Motion Engine category. It lives in the glowkit-motion crate, enabled by the motion feature of glowkit (on by default). It reads its colors from the active glowkit theme, so it matches the rest of your app in light, dark or a custom brand theme, and every color, size and timing has a setter to override it.

The engine under every glowkit animation, exposed for your own UI: springs, keyframes, GSAP-style timelines, variants with stagger, enter and exit presence, FLIP layout animation, shared elements, drag with inertia and snapping, scroll-linked values, motion paths and shape morphing.
