Dragging Ball

A ball you grab: it swells under the pointer, squeezes as you hold it and wobbles home when you let go.

Category Micro-interactionsCrate glowkit-effectsFeature effectsegui 0.37
Try it liveMore Micro-interactions

Usage

Add glowkit next to eframe:

cargo add glowkit eframe

Then draw it inside any egui Ui:

use glowkit::prelude::*;
use glowkit::effects::DragBall;

ui.add(DragBall::new().size(56.0).stretch(0.36).give(0.5));

Prefer to own the code? The glowkit CLI copies this component's source into your project, shadcn-style:

cargo install glowkit-cli
glowkit add drag-ball

Equivalent to

If you know this pattern from Bencho, Dragging Ball is the Rust version: an original egui implementation, not a port, that runs natively and in WebAssembly.

About Dragging Ball

Dragging Ball is one of 71 components in glowkit's Micro-interactions category. It lives in the glowkit-effects crate, enabled by the effects feature of glowkit (on by default). It reads its colors from the active glowkit theme, so it matches the rest of your app in light, dark or a custom brand theme, and every color, size and timing has a setter to override it.

Small, physical details that make an app feel finished: liquid toggles, slide-to-confirm, swipe actions, reorderable lists, pull to refresh, emoji reactions, rolling counters, success checks, error shakes and notification badges, each tuned with springs.
