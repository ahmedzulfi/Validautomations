Bounce Sidebar

Sidebar links with a dot that hops to the one you pick: it leaps out in an arc, stretches in flight and lands with a squash.

Category NavigationCrate glowkit-interactionsFeature interactionsegui 0.37
Try it liveMore Navigation

Usage

Add glowkit next to eframe:

cargo add glowkit eframe

Then draw it inside any egui Ui:

use glowkit::prelude::*;
use glowkit::interactions::BounceSidebar;

let mut active = 1usize;
ui.add(BounceSidebar::new(&mut active, ["Overview", "Components", "Motion", "Templates", "Changelog"]));

Prefer to own the code? The glowkit CLI copies this component's source into your project, shadcn-style:

cargo install glowkit-cli
glowkit add beui-bounce-sidebar

Equivalent to

If you know this pattern from beUI, Bounce Sidebar is the Rust version: an original egui implementation, not a port, that runs natively and in WebAssembly.

About Bounce Sidebar

Bounce Sidebar is one of 18 components in glowkit's Navigation category. It lives in the glowkit-interactions crate, enabled by the interactions feature of glowkit (on by default). It reads its colors from the active glowkit theme, so it matches the rest of your app in light, dark or a custom brand theme, and every color, size and timing has a setter to override it.

Menus and navigation that move with intent: bubble, pill, gooey and staggered menus, card navs, floating and resizable navbars, sidebars, command palettes, tables of contents and morphing tab bars.
