Text Animations

Split Text

Letters (or words) rise into place one after another with a springy overshoot. Optional line mask for a pull-up reveal.

Category Text AnimationsCrate glowkit-textFeature textegui 0.37
Try it liveMore Text Animations

Usage

Add glowkit next to eframe:

cargo add glowkit eframe

Then draw it inside any egui Ui:

use glowkit::prelude::*;
use glowkit::text::{SplitText, SplitBy};

ui.add(SplitText::new("Hello, you!").size(56.0).trigger(Trigger::OnClick));
ui.add(SplitText::new("Words pull up from behind a mask")
    .split_by(SplitBy::Words)
    .mask(true)
    .size(24.0));

Prefer to own the code? The glowkit CLI copies this component's source into your project, shadcn-style:

cargo install glowkit-cli
glowkit add split-text

About Split Text

Split Text is one of 57 components in glowkit's Text Animations category. It lives in the glowkit-text crate, enabled by the text feature of glowkit (on by default). It reads its colors from the active glowkit theme, so it matches the rest of your app in light, dark or a custom brand theme, and every color, size and timing has a setter to override it.

Per-glyph text effects drawn straight into egui: shimmering and gradient text, blur and split reveals, decrypting and scrambling characters, typewriters, rotating words, counters that roll to a value, glitch, wave and proximity effects. Each one is a single widget you add with ui.add().
