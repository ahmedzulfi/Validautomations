Pour

A filter bar of liquid ink: tap a tag and the count pill pours into it, floods and swallows it while the count rolls; tap again and it drains, necks and snaps free.

Category Inputs & FormsCrate glowkit-interactionsFeature interactionsegui 0.37
Try it liveMore Inputs & Forms

Usage

Add glowkit next to eframe:

cargo add glowkit eframe

Then draw it inside any egui Ui:

use glowkit::prelude::*;
use glowkit::interactions::PourFilter;

ui.add(PourFilter::new(&["Sauna", "Lakeside", "Wood stove", "Dogs OK"], &mut selected)
    .total(86).noun("cabins"));

Prefer to own the code? The glowkit CLI copies this component's source into your project, shadcn-style:

cargo install glowkit-cli
glowkit add snap-pour

Equivalent to

If you know this pattern from Snapblocks, Pour is the Rust version: an original egui implementation, not a port, that runs natively and in WebAssembly.

About Pour

Pour is one of 13 components in glowkit's Inputs & Forms category. It lives in the glowkit-interactions crate, enabled by the interactions feature of glowkit (on by default). It reads its colors from the active glowkit theme, so it matches the rest of your app in light, dark or a custom brand theme, and every color, size and timing has a setter to override it.

Form controls with motion: one-time-code inputs with autofill, ratings, color pickers, calendars, file dropzones, vanishing inputs, day/night switches and availability schedulers.
