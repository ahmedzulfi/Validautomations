Bubble Menu

A round menu button that bursts into tilted pill links on bouncy springs; hovered pills straighten and flood with color.

Category NavigationCrate glowkit-effectsFeature effectsegui 0.37
Try it liveMore Navigation

Usage

Add glowkit next to eframe:

cargo add glowkit eframe

Then draw it inside any egui Ui:

use glowkit::prelude::*;
use glowkit::effects::BubbleMenu;

let r = BubbleMenu::new(&["Home", "About", "Projects", "Blog", "Contact"])
    .logo("◉ glowkit")
    .show(ui);
if let Some(i) = r.inner { /* navigate to item i */ }

Prefer to own the code? The glowkit CLI copies this component's source into your project, shadcn-style:

cargo install glowkit-cli
glowkit add bubble-menu

About Bubble Menu

Bubble Menu is one of 18 components in glowkit's Navigation category. It lives in the glowkit-effects crate, enabled by the effects feature of glowkit (on by default). It reads its colors from the active glowkit theme, so it matches the rest of your app in light, dark or a custom brand theme, and every color, size and timing has a setter to override it.

Menus and navigation that move with intent: bubble, pill, gooey and staggered menus, card navs, floating and resizable navbars, sidebars, command palettes, tables of contents and morphing tab bars.
