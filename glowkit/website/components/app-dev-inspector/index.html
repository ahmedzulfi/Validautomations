Profiler / Inspector

A developer profiler for a running process: live frame-time chart with budget lines, a collapsible span tree, a zoomable flame graph (wheel, drag, double-click to fit, F resets), a property inspector with per-frame history and a filterable log console (Space pauses, ← → step frames).

Category TemplatesCrate glowkit-templatesFeature templatesegui 0.37
Try it liveMore Templates

Usage

Add glowkit next to eframe:

cargo add glowkit eframe

Then draw it inside any egui Ui:

use glowkit::prelude::*;
use glowkit::templates::DevInspectorApp;

let mut app = DevInspectorApp::default();
app.show(ui);

Prefer to own the code? The glowkit CLI copies this component's source into your project, shadcn-style:

cargo install glowkit-cli
glowkit add app-dev-inspector

About Profiler / Inspector

Profiler / Inspector is one of 43 components in glowkit's Templates category. It lives in the glowkit-templates crate, enabled by the templates feature of glowkit (on by default). It reads its colors from the active glowkit theme, so it matches the rest of your app in light, dark or a custom brand theme, and every color, size and timing has a setter to override it.

Complete screens you can start from: landing, pricing, auth, onboarding and error pages, plus working app templates such as an analytics dashboard, CRM, e-commerce admin, mail client, team chat, AI assistant, agent session manager, local LLM chat, trading terminal and profiler.
