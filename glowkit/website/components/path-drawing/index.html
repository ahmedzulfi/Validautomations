Motion Engine

Path Drawing

Any polyline drawn progressively with a gradient stroke and a glowing pen tip, then erased: like animating SVG pathLength.

Category Motion EngineCrate glowkit-motionFeature motionegui 0.37
Try it liveMore Motion Engine

Usage

Add glowkit next to eframe:

cargo add glowkit eframe

Then draw it inside any egui Ui:

use glowkit::prelude::*;
use glowkit::motion::{MotionPath, Keyframes, Repeat};

let path = MotionPath::smooth(&points, false);
let k = Keyframes::new([(0.0, 0.0_f32), (0.6, 1.0), (1.0, 1.0)]).repeat(Repeat::Infinite).play(ui, id);
path.paint_progress(painter, k, 4.0, |t| gradient(&colors, t));

Prefer to own the code? The glowkit CLI copies this component's source into your project, shadcn-style:

cargo install glowkit-cli
glowkit add path-drawing

About Path Drawing

Path Drawing is one of 17 components in glowkit's Motion Engine category. It lives in the glowkit-motion crate, enabled by the motion feature of glowkit (on by default). It reads its colors from the active glowkit theme, so it matches the rest of your app in light, dark or a custom brand theme, and every color, size and timing has a setter to override it.

The engine under every glowkit animation, exposed for your own UI: springs, keyframes, GSAP-style timelines, variants with stagger, enter and exit presence, FLIP layout animation, shared elements, drag with inertia and snapping, scroll-linked values, motion paths and shape morphing.
