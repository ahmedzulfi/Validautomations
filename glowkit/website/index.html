Why glowkit

Website-grade polish for desktop apps.

Everything you love about the modern web component ecosystem, rebuilt from scratch in Rust.

A real motion engine

Springs, keyframes, GSAP-style timelines, variants with stagger, enter and exit presence, FLIP layout animation and drag with inertia. Motion for Rust

Native everywhere

100% Rust on egui 0.37. One codebase for Windows, macOS, Linux and the web through WebAssembly. No Electron, no webview.

Real agent streams

glowkit-stream connects AG-UI, the Vercel AI SDK, ACP, rig and async-openai to the AI components. AI agent UIs

3D without the setup

A built-in software 3D renderer draws lit, depth-sorted meshes straight into egui: globes, model viewers, particle clouds. 3D components

Themeable tokens

Semantic tokens with five presets. One call restyles every glowkit component and egui's own widgets.

MCP server and CLI

glowkit-mcp gives coding agents the real API: search, exact use paths, setters and templates. The glowkit CLI copies component source into your project.

Get started

Two lines in Cargo.toml.

Add glowkit next to eframe, install a theme, and drop components into any egui layout.

  • Builder APIs that feel like egui: ui.add(Thing::new(..))
  • Theme colors by default, setters to override everything
  • Idle apps stay idle: one-shot animations stop repainting
  • Dual-licensed MIT / Apache-2.0
// Cargo.toml: glowkit = "0.1", eframe = "0.37"
use glowkit::prelude::*;
use glowkit::{backgrounds::Aurora, effects::ShimmerButton, text::ShinyText};

impl eframe::App for App {
    fn ui(&mut self, ui: &mut egui::Ui, _: &mut eframe::Frame) {
        Theme::dark().install(ui.ctx());
        egui::CentralPanel::default().show(ui, |ui| {
            Aurora::new().paint(ui, ui.max_rect());
            ui.add(ShinyText::new("Hello from Rust").size(48.0));
            if ui.add(ShimmerButton::new("Get started")).clicked() {
                // ...
            }
        });
    }
}
