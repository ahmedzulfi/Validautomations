Why glowkit

Website-grade polish for desktop apps.

Everything you love about the modern web component ecosystem, rebuilt from scratch in Rust.

Animated by default

31 easing curves, springs, staggering and triggers (on appear, loop, hover, click) power every component.

Native everywhere

One codebase for Windows, macOS, Linux and the web. No webview, no JavaScript, no Electron.

Themeable tokens

Semantic tokens with five presets. One call restyles glowkit and egui's own widgets.

GPU meshes

Gradients, glows and "shader" backgrounds are vertex-colored meshes: smooth and cheap.

Modular crates

Text, backgrounds, effects, components, charts, AI and blocks, each behind a cargo feature.

AI-ready

Streaming markdown, prompt input, reasoning, tool calls, sources, voice orb and waveforms.

Get started

Two lines in Cargo.toml.

Add glowkit next to eframe, install a theme, and drop components into any egui layout.

  • Builder APIs that feel like egui: ui.add(Thing::new(..))
  • Theme colors by default, setters to override everything
  • Idle apps stay idle: one-shot animations stop repainting
  • Dual-licensed MIT / Apache-2.0
// Cargo.toml: glowkit = "0.1", eframe = "0.37"
use glowkit::prelude::*;
use glowkit::{backgrounds::Aurora, effects::ShimmerButton, text::ShinyText};

impl eframe::App for App {
    fn ui(&mut self, ui: &mut egui::Ui, _: &mut eframe::Frame) {
        Theme::dark().install(ui.ctx());
        egui::CentralPanel::default().show(ui, |ui| {
            Aurora::new().paint(ui, ui.max_rect());
            ui.add(ShinyText::new("Hello from Rust").size(48.0));
            if ui.add(ShimmerButton::new("Get started")).clicked() {
                // ...
            }
        });
    }
}
